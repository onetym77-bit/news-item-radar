# 편집자 피드백

브리핑을 검토한 뒤 후보마다 최소 결정·이유 코드를 남긴다. 긴 의견은 선택 사항이다. 예약 작업은 `처리 상태: 미반영`인 항목만 읽고 반영 후 상태와 날짜를 바꾼다.

## 이유 코드

- `NOVELTY`: 새로움·반전 부족
- `CITIZEN`: 시민 이해관계·행동 근거 부족
- `EVIDENCE`: 원자료·독립 근거 부족
- `VISUAL`: 화면·현장 장면 부족
- `ACCESS`: 섭외·접근 난도
- `TIMING`: 시의성 부족 또는 시점 부적절
- `DUPLICATE`: 기존 보도·장부 후보와 중복
- `SELECTED`: 취재·제작 가치가 확인됨

## 작성 형식

### YYYY-MM-DD / 아이템명

- 결정: 채택 | 보류 | 탈락 | 영구 제외
- 이유 코드: NOVELTY | CITIZEN | EVIDENCE | VISUAL | ACCESS | TIMING | DUPLICATE | SELECTED
- 한 줄 이유:
- 더 보고 싶은 방향:
- 처리 상태: 미반영
- 반영 날짜:

## 피드백 기록

### 2026-09-08 / 중심 질문과 경쟁 가설을 갖춘 질문 품질

- 결정: 채택
- 이유 코드: SELECTED
- 한 줄 이유: 분포·격차를 묻는 데서 멈추지 않고 시민 손실, 공식 설명과의 긴장, 경쟁 가설, 책임 주체, 폐기 조건까지 연결해야 기획기사를 끌고 갈 질문이 됨
- 더 보고 싶은 방향: 후보마다 중심 질문은 하나만 두고 구조 원인과 자연적·기술적 대안 설명을 함께 검증하며 어떤 결과면 질문을 버릴지 미리 제시할 것
- 처리 상태: 반영
- 반영 날짜: 2026-09-08

### 2026-09-08 / 현상에서 새로운 질문을 만드는 발굴 방식

- 결정: 채택
- 이유 코드: SELECTED
- 한 줄 이유: 서울시 외국인 카드 소비 1조 원 발표처럼 단순 현상도 지역·업종 집중, 원인, 자연스러움, 대책을 연쇄 질문하면 기획기사로 발전할 수 있음
- 더 보고 싶은 방향: 새로운 신호뿐 아니라 기존 발표·통계의 총액과 평균을 분포·격차·구성·수혜 구조로 비틀어 검증할 것
- 처리 상태: 반영
- 반영 날짜: 2026-09-08

## 주간 학습 집계

주간 감사는 편집자 결정이 있는 항목만 분모로 사용해 출처군별 채택률, E등급별 채택률, 반복 탈락 이유, 채택 후 제작 중단 이유를 집계한다. 피드백이 없으면 학습 상태를 `자료 없음`으로 기록하며 성능 개선으로 해석하지 않는다.
