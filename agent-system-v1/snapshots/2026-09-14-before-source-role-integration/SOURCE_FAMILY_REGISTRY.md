# 출처군과 독립 근거 판정

## 출처군

| 코드 | 출처군 | 예시 | 용도 |
|---|---|---|---|
| PRICE | 가격·거래 | 요금표, 실거래, 영수증, 매물, 중고거래 | 실제 지출·거래 변화 발견 |
| BEHAVIOR | 예약·이용행동 | 대기, 매진, 취소, 검색, 이동, 운영시간 | 시민 행동 변화 발견 |
| VOICE | 시민 경험 | 당사자 진술, 상담, 민원, 반복 후기 | 손실·불편·선택 이유 확인 |
| FIELD | 현장·사업자 | 점포 운영, 폐업·이전, 구인, 현장 관찰 | 장소와 운영 변화 확인 |
| INDUSTRY | 업계·연구 | 협회, 기업 공시, 민간 보고서, 연구기관 | 시장 구조와 원인 가설 보조 |
| PUBLIC | 공공 원자료 | 행정통계, 공공데이터, 의회 원문 | 규모·분포·제도 검증 |
| MEDIA | 언론 보도 | 취재 기사, 방송 리포트 | 발견 단서와 선행보도 확인 |
| SOCIAL | 공개 SNS·영상 | 유튜브, 공개 게시물, 공개 커뮤니티 | 시민 언어와 섭외 단서 |

## 독립성 판정

- 서로 다른 URL이나 언론사라는 이유만으로 독립 근거가 되지 않는다.
- 같은 보도자료·통계·조사·당사자 발언을 재인용하면 하나의 근거 계보로 묶는다.
- MEDIA + MEDIA라도 각 기사가 별도 현장 취재와 별도 원자료를 가진 경우에만 독립으로 인정한다.
- SOCIAL의 여러 게시물이 동일 영상이나 동일 행사 홍보물을 재유통하면 하나로 센다.
- 독립 근거군은 결론을 반복하는 자료가 아니라 서로 다른 사실 층을 확인해야 한다.

## 시민 장면 상태

- 관찰됨: 기자·공개 원자료·현장 기록에서 행동을 직접 확인
- 당사자 진술: 구체적 경험을 한 당사자의 공개 또는 취재 진술 확인
- 간접 보도: 언론·제3자의 설명만 확인
- 취재 예정: 현장과 대상은 정했지만 행동을 아직 확인하지 않음
- 없음: 시민 행동 장면을 제시할 근거가 없음

S2 이상은 관찰됨 또는 당사자 진술이 원칙이다. 간접 보도만 있는 후보는 공익상 긴급한 예외가 아니라면 S1에 둔다.

## 핵심 생활 의제

매 회차는 출처군별 건수를 채우지 않고 다음 의제에서 구조 변화를 찾는다.

1. 주거
2. 노동
3. 돌봄·의료
4. 교육
5. 교통·이동
6. 생활물가
7. 디지털 권리
8. 안전·환경
9. 지역경제·생활서비스

하루 회차는 최근 변화와 장부 공백을 고려해 최소 5개 의제를 탐색한다. 주거·노동·돌봄·교통·생활물가는 핵심 의제로 매일 확인하고, 나머지는 순환한다. 유효 질문 원석이 없으면 0건으로 기록한다.

## 출처군의 역할

- 출처군은 탐색 할당량이 아니라 서로 다른 사실 층을 구분하는 태그다.
- 감사·판결·예산·공시·행정통계·민원 등 PUBLIC 원자료는 구조 변화 발견에 사용할 수 있다.
- 보도자료·서비스 홍보·기관 성과 소개도 객관적 결과가 있고 분해·비교할 수 있으면 질문 원석이 될 수 있다. 기관의 해석은 독립 근거가 아니다.
- 질문 게이트는 단일 원천으로도 통과할 수 있다. 기사 게이트와 S2 승격에는 서로 다른 사실 층과 독립 근거가 필요하다.
