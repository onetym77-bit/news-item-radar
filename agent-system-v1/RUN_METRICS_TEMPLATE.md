# 일일 브리핑 실행 계측 템플릿 v1.6

아래 항목을 일일 브리핑의 `실행 계측` 절에 빠짐없이 채운다. 측정할 수 없는 값은 공란이나 추정값 대신 `계측 불가`와 이유를 적는다.

## 질문 품질 진단

- 근거 앵커: 구체 문제 징후 / 분해 가능한 구조 자료 / 진입 HOLD / 진입 FAIL:
- 근거 앵커 없이 피해자·손실을 만든 미채점(N/A) 건수:
- 질문 품질 PASS / HOLD / FAIL:
- PASS 평균 점수: 0/12
- 템플릿 질문 상한 적용 건수: 0
- 중심 질문 1개 작성 완료: 0/0
- 시민 손실 가설 작성 완료: 0/0
- 경쟁 가설 2개 이상 작성 완료: 0/0
- 기사 전환·축소·폐기 판정선 작성 완료: 0/0
- 독창성 PASS / HOLD / FAIL: 0 / 0 / 0
- 시민 손실 근거 탐색 완료: 0/0
- 반대 근거 탐색 완료: 0/0
- 24시간 이내 최소 판정 실험 작성 완료: 0/0
- 질문 가족 중복 검토 / 병합: 0 / 0

근거 앵커 집계는 질문 점수 전 단계다. 사업명·단일 행정기록만 있는 미채점 항목은 질문 원석과 PASS 분모에서 제외한다. PASS 분모는 질문 품질 게이트 PASS 원석 수다. “어디에 집중됐나”, “지역별로 다른가”, “실제로 불편한가”에 머문 질문은 템플릿 질문 상한 적용 건수에 포함한다.

판정 규칙:

- 핵심 생활 의제 5개 이상을 탐색하고 질문 게이트 PASS 원석 중 2~4건을 실제 분해·비교하면 PASS다.
- 질문 원석이 0~4건이어도 의제 탐색과 제외 이유가 기록되면 `소수 정상`이며 PASS가 가능하다.
- 정책·장부·최근 기록을 읽지 못했거나 실행·저장·건수 정합성을 확인할 수 없으면 FAIL이다.
- 유효 후보가 0건이어도 편집 산출 판정은 후보 없음으로 정상 기록할 수 있다. 이 사실이 탐색 수행 미달을 PASS로 바꾸지는 않는다.
