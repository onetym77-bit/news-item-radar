# 질문 독창성·최소 검증 게이트 v1.5

## 목적

문장이 날카롭다는 이유만으로 출처의 해석을 되풀이한 질문을 통과시키지 않는다. 질문 품질 점수와 별도로 **출처를 넘어선 편집적 추가**, **반대 근거 탐색**, **짧은 시간 안에 가능한 첫 판정**을 확인한다.

## 1. 출처 프레임 차감

질문 품질 PASS/HOLD 원석마다 다음을 먼저 적는다.

- `출처 프레임`: 최초 원천이 직접 주장하거나 이미 설명한 결론
- `편집적 추가`: 출처가 답하지 않은 새 관계·영향 집단·원인 대립·책임 질문
- `선행보도 질문`: 같은 주제가 아니라 같은 중심 질문을 이미 검증한 보도가 있는지

원문의 제목·요약·결론을 지웠을 때도 다음 중 하나가 새로 남아야 `PASS`다.

1. 두 변수 사이의 검증 가능한 새 관계
2. 출처가 다루지 않은 구체 영향 집단과 행동 변화
3. 서로 다른 원인을 가르는 비교축
4. 결정 주체와 바꿀 수 있는 규칙

### 판정

- `PASS`: 출처·주요 선행보도가 답하지 않은 편집적 추가가 명확하다.
- `HOLD`: 새 분해축은 있으나 출처의 결론을 확장한 수준이거나 선행보도 확인이 덜 됐다.
- `FAIL`: 제목·표현만 바꾸었거나 “누가 손해인가·대책은 무엇인가”를 일반적으로 덧붙인 재진술이다.

독창성 `HOLD/FAIL`은 질문 품질 점수가 8점 이상이어도 우선 검증 대상이 될 수 없다. 새 비교축을 만든 뒤 재평가한다.

## 2. 양방향 근거 탐색

독창성 PASS 원석을 우선 검증할 때 아래 두 경로를 모두 실제 검색한다.

- **시민 손실 경로:** 민원·상담·분쟁·가격·거래·계약·영수증·이용 포기·이동·폐업·현장 관찰 중 하나 이상
- **반대 근거 경로:** 구성 효과·기저효과·경계 변경·표본·계절·선호·대체 공급 등 구조 가설을 약화할 자료

근거가 나오지 않아도 검색 시도와 결과를 기록한다. 시민 손실이 발견되지 않은 질문은 S1 이하이며, 반대 근거를 찾지 않은 질문은 기사 게이트로 보낼 수 없다.

## 3. 최소 판정 실험

우선 검증 질문마다 전체 취재 계획보다 작은 `최소 판정 실험`을 한 문장으로 쓴다.

- 한 표, 한 공간 단위, 한 조건 표준화, 한 짧은 표본처럼 4시간 또는 24시간 안에 구조 가설과 대안 가설의 방향을 가를 수 있어야 한다.
- `4시간 이내`, `24시간 이내`, `장기` 중 예상 시간을 기록한다.
- 첫 판정이 24시간 안에 불가능하면 일일 우선 검증에서 제외하고 장기 관찰 대기열로 보낸다.

## 4. 왜 지금인가

현상의 시간 유형을 기록한다.

- `새 사건`: 실제 상태가 최근 바뀜
- `새 자료`: 과거 현상을 보여주는 자료가 최근 공개됨
- `누적 구조`: 오래된 변화가 임계점·제도 변경·새 시민 행동과 만남
- `재발견`: 새 계기 없이 오래된 현상을 다시 소개함

`새 자료`는 자료 공개 자체가 아니라 새로 검증 가능한 불일치가 있어야 한다. `누적 구조`는 최근 임계점이나 행동 신호가 필요하다. `재발견`은 일일 우선 검증에서 제외한다.

## 5. 출처 편중 보정

공공 발표·통계·공공연구에서 시작한 원석이 전체의 60%를 넘거나 우선 검증이 모두 같은 계보면, 우선순위 확정 전에 `PRICE·BEHAVIOR·VOICE·FIELD·INDUSTRY`에서 한 차례 보정 탐색을 수행한다.

이는 약한 비공공 원석을 억지로 통과시키는 할당량이 아니다. 사용한 검색 경로와 원석 0건을 포함한 결과를 기록한다. 보정 탐색을 하지 않으면 탐색 수행 판정은 `DEGRADED` 이하이다.

## 6. 질문 가족 중복

제목이나 최초 통계가 아니라 `영향 집단 + 시민 손실 + 작동 원리 + 결정 주체`로 질문 가족을 만든다. 네 요소 중 세 개 이상이 같으면 같은 가족으로 보고 기존 `item_id`를 부모로 지정한다.

- 같은 질문 가족은 한 회차 우선 검증에 한 건만 둔다.
- 새 통계나 지역 분해는 별도 아이템이 아니라 부모 질문의 보조 가설·새 근거로 합친다.
- 작동 원리나 결정 주체가 실제로 다를 때만 독립 질문으로 유지한다.
- 병합 여부가 모호하면 `중복 검토`로 표시하고 두 질문을 동시에 상위 순위에 올리지 않는다.

## 7. 질문 품질 점수와의 관계

질문 품질 점수는 질문의 구조를, 이 게이트는 질문의 새로움과 첫 검증 가능성을 평가한다. 두 값을 합산하지 않는다.

- 우선 검증 진입: 질문 품질 PASS + 독창성 PASS + 최소 판정 24시간 이내
- 기사 게이트 진입: 위 조건 + 시민 손실 경로 탐색 + 반대 근거 경로 탐색
- S2 이상: 실제 시민 행동 또는 당사자 진술과 독립 근거 계보가 기존 규칙대로 필요
