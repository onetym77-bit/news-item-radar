# 구조 레이더 v1 — 원천 등록표

## 바로 연결할 원천

### 서울시 상권분석서비스

- 점포-자치구: 업종별 전체·일반·프랜차이즈 점포 수, 개업·폐업 수와 비율
- 추정매출-상권/행정동/자치구: 상권 내 점포의 추정매출
- 상권변화지표: 상권의 변화 방향을 해석하는 보조 지표
- 용도: “어느 동네의 어느 생활 업종이 어떻게 재편되는가”라는 질문의 출발점
- 주의: 분기 단위일 수 있으므로 최신 기준년·분기를 결과에 반드시 표시한다.

### 서울 생활인구

- 내국인·장기 외국인·단기 외국인 생활인구
- 행정동·자치구·250m 단위, 시간·일 단위 집계
- 용도: “사람들이 사는 곳과 머무는 곳의 시간대 차이가 어떻게 변하는가”를 확인
- 주의: 주말·평일, 휴일, 날씨·행사 영향을 분리하지 않으면 기사 후보로 승격하지 않는다.

## 2차 후보 원천

- 버스 노선·정류장·시간대별 승하차: 생활권 접근성 변화의 보조 확인
- 지하철 역별 승하차: 이동 축 변화의 보조 확인
- 공영주차장 요금·잔여대수: 시설 공급과 실제 이용의 불일치 확인

## 접근·키 관리

서울 열린데이터광장은 서울시 홈페이지 로그인 후 OpenAPI 인증키를 신청하면 발급받을 수 있다. API 호출은 한 번에 최대 1,000행 단위로 나눠야 하는 데이터셋이 있으므로, 수집기는 페이지네이션과 데이터 기준일 기록을 기본으로 갖춰야 한다.

환경변수 이름:

```text
SEOUL_OPEN_API_KEY
```

이 키는 결과 파일이나 이 문서에 기록하지 않는다.
