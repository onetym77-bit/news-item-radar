# 상권 전년 동분기 분석 규칙

- 현재 데이터의 최신 기준분기는 `20261`(2026년 1분기)이며, 기본 비교 대상은 `20251`(2025년 1분기)이다.
- 상권 매출 데이터는 분기 갱신이며, 2024년부터 공간 단위가 표준단위구역 기준으로 변경됐으므로 2021년 이후 자료만 동일 계열에서 비교한다.
- 분석기는 `THSMON_SELNG_AMT`와 `STOR_CO`를 사용한다.
- 매출 증감은 사업체 수·가격·대형 점포·카드 포착 범위의 영향을 받으므로, 소비 변화나 시민 생활의 원인으로 단정하지 않는다.
- 수치 관찰은 S1이다. 생활인구·관심 레이더·현장 관찰이 더해지기 전에는 기획기사 후보가 아니다.
