# 정보소통광장 접근 방식 확인

확인일: 2026-09-17

## 결론

정보소통광장의 공개 결재문서 목록·상세 웹 화면을 읽는 데 별도 API 키가 필요하다는 현재 공식 안내는 확인되지 않았다. 공개 웹 화면은 로그인이나 키 없이 열람하도록 제공된다.

서울 열린데이터광장의 OpenAPI는 별도 경로다. 이 API를 호출하려면 열린데이터광장에서 인증키를 발급받아야 한다. 따라서 열린데이터광장 키가 정보소통광장 웹 수집 오류를 해결한다고 간주하지 않는다.

정보소통광장에는 OPEN API로 표시되는 공개 검색 화면과 과거의 OpenAPI 신청 안내 흔적이 있으나, 현재 사용할 수 있는 공식 명세·신청 절차·인증 방식은 이번 확인에서 검증하지 못했다. 확인되지 않은 API 주소나 키를 구현하지 않는다.

## 시스템 적용 원칙

1. 현재 opengov_approvals L0 시험은 공개 목록과 상세 웹 화면을 대상으로 유지한다.
2. NETWORK_ERROR·시간초과는 인증 실패가 아니다. HTTP 401·403 또는 공식 인증 안내가 확인되기 전에는 API_KEY_MISSING으로 분류하지 않는다.
3. 공개 웹 접근이 반복 실패하면 네트워크·로봇 차단·응답 크기·리디렉션을 각각 진단한다.
4. 열린데이터광장에서 정보소통광장 결재문서 데이터셋과 서비스명이 확인될 때에만 별도 키 방식의 보조 어댑터를 검토한다.
5. 키를 발급받더라도 저장소에 넣지 않고 GitHub Actions secret으로만 사용한다.

## 확인한 공식 경로

- 공개 결재문서 목록: https://opengov.seoul.go.kr/sanction/list
- 정보소통광장 공개 검색 화면: https://opengov.seoul.go.kr/openweb
- 서울 열린데이터광장 OpenAPI 이용 안내: https://data.seoul.go.kr/together/guide/useGuide.do
- 서울 열린데이터광장 인증키 신청 안내: https://data.seoul.go.kr/together/mypage/actkeyMain.do

## 남은 확인

정보소통광장 운영 부서가 현재 별도 OpenAPI를 외부에 제공하는지, 제공한다면 최신 명세와 신청 창구가 무엇인지 공식 문의로 확정할 수 있다. 그 확인 전에는 공개 웹 수집과 열린데이터광장 API를 서로 다른 접근 방식으로 취급한다.
