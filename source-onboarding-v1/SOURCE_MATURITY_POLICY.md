# 신규 소스 성숙도 게이트와 얇은 수집 규격

목적은 신규 소스를 완성품으로 만들기 전에 접근성·공급량·편집 가치를 비교하되, 미성숙한 자료가 질문·기사·장부로 넘어가지 못하게 하는 것이다. 이 규격은 기존 운영 소스의 역할을 자동 변경하지 않는다.

## 성숙도와 허용 범위

| 단계 | 확인할 것 | 허용 | 금지 |
|---|---|---|---|
| L0 접속 시험 | 공식 경로·응답·실패 상태 | 접속 진단 | 게시물 기록·질문·브리핑 |
| L1 목록 수집 | 고유번호·제목·항목 날짜·상세주소 | 최대 20건 목록 표본 | 본문 해석·질문·브리핑 |
| L2 본문 표본 | 제목과 상세 대응·제한 본문·개인정보 경계 | 사람의 소스 가치 평가 | 질문 생성·브리핑 |
| L3 의미 해석 시험 | 단위·상태·중복·변화 규칙 | 검증 질문만, 파생 상태 저장, 그림자 예약 | 브리핑·장부·기사 판정 |
| L4 7일 그림자 검증 | 사람 판정 완료율·오탐·검증 가능한 질문 수 | 사람 검토함과 전이 제안 | 자동 장부·자동 기사 |
| L5 운영 승인 | 편집 승인·안정성·정밀도 | 승인된 역할 범위의 정식 운영 | 자동 편집 판정·자동 장부 |

L4 이상은 최소 7일 관측과 사람 판정 완료율 80% 이상을 요구한다. L5는 별도의 운영 승인값이 필요하다. 소스 수집기는 어느 단계에서도 ITEM_LEDGER.csv나 질문 품질 장부를 자동 수정하지 않는다.

## 얇은 관측 공통 형식

관측 묶음은 다음을 가진다.

- 등록된 source_id와 현재 성숙도
- 수집 시각과 공식 소스 주소
- 접근 상태: 성공·부분 성공·실패·미시도
- 실제 확인 범위
- 편집 해석 상태: 항상 NOT_EVALUATED
- 최대 20개의 표준 기록

L1 이상의 표준 기록은 다음을 가진다.

- 원사이트 고유번호
- 제목
- 상세 원문 주소
- 게시일 값과 날짜 상태: 검증·후보·미확인
- 관측 시각
- 접근·본문 상태
- 원문 지문
- 선택적으로 260자 이하의 개인정보 제거 표본

접속 실패는 0건이 아니다. 실패 상태에서 빈 목록을 성공 결과로 내보낼 수 없으며, L0 접속 시험은 게시물 기록을 내보낼 수 없다.

## 얇은 단계의 금지 정보

공통 검증기는 얇은 관측 안의 다음 정보가 발견되면 실패한다.

- 중심 질문·시민 손실·기사 후보·품질 점수
- 피해 확정·피해자 수
- 원문 HTML·본문 전체
- 작성자명·이메일·전화·연락처
- 중복 고유번호·중복 상세주소
- 검증됐다고 표시했지만 값이 없는 게시일

짧은 본문 표본도 완전한 비식별화를 보장하지 않는다. 필요하지 않으면 저장하지 않고, 저장하더라도 사람의 소스 가치 평가 범위를 넘어 자동 전파하지 않는다.

## 승격 판단

수집량은 승격 기준이 아니다. 다음을 함께 본다.

1. 목록과 상세 원문의 안정적 대응률
2. 날짜·고유번호·중복 판별 정확도
3. 실제 문제 징후 또는 분해 가능한 구조 자료의 비중
4. 사람이 검증 가능한 질문을 만들 수 있는 비중
5. 오탐·미탐·접속 실패율
6. 기존 소스와 다른 사실 층을 제공하는지
7. 사람 판정 완료율과 기각 사유

L0~L2 결과로 소스를 핵심원·보조원·검증원으로 확정하지 않는다. 소스의 가치가 낮아 보이더라도 본문 확보 실패와 실제 무가치를 분리한다.

## 현재 등록 범위

source_maturity_registry.json에는 정식 운영 중인 모든 소스가 아니라 신규 편입을 평가 중인 소스만 둔다. 기존 운영 역할은 source-scout-v1/SOURCE_ROLE_REGISTRY.md가 계속 기준이다. 두 등록부가 충돌하면 자동 승격하지 않고 문서 불일치로 보류한다.

첫 등록 대상은 25개 자치구의회, 응답소 통계, 건설알림이, 시민제안, 환경영향평가, 정보소통광장 결재문서, 서울시 감사 결과, 시장·구청장 공식 SNS망이다.

## 넓은 시험의 공통 비교

신규 후보는 개별 전용 수집기를 먼저 완성하지 않고, 가능한 경우 동일한 최대 20건 표본으로 기술 상태와 편집 가치를 비교한다. 세부 절차와 판정 기준은 WIDE_SOURCE_SCREENING.md를 따른다.

- 기술 비교: 접근·상세 대응·본문 확보·날짜 검증·고유 본문·미해결 주소
- 편집 비교: 사람 판정 완료율·유효 단서·잡음·중복·판독 불가
- 기술 실패는 콘텐츠 가치 0점으로 환산하지 않는다.
- L0·L1 또는 본문 확보율 60% 미만은 편집 가치 평가 대상이 아니다.
- 비교 결과는 DEEPEN·AUXILIARY·STOP_OR_VERIFY_ONLY 후보 제안일 뿐 자동 승격이 아니다.
