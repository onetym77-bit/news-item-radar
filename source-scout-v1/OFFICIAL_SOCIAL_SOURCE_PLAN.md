# 서울 공직자 공식 SNS·영상 소스 확장 계획

## 목적

서울시장과 25개 구청장 주변에서 먼저 나타나는 정책 변화, 현장 갈등, 행정 실패, 공개 발언을 빠르게 발견하되, 짧은 영상이나 일방적 게시물을 곧바로 사실로 확정하지 않는다.

## 수집 범위와 우선순위

### 1단계 · 공식 원계정

- 서울시장, 서울시, 25개 구청장, 25개 자치구의 공식 홈페이지·블로그·유튜브·공개 SNS
- 계정명 검색이 아니라 사람이 확인한 계정 URL과 플랫폼 ID를 소스 등록부에 저장
- 게시물 URL, 게시 시각, 본문, 자막·설명, 영상 길이, 원계정 여부를 수집
- 공식 계정에서 삭제·수정된 경우 단정하지 않고 변경 시각과 확인 가능한 차이만 기록

### 2단계 · 공직자가 등장한 외부 콘텐츠

- 언론사·지역매체·기관·단체의 유튜브와 공개 SNS에서 시장·구청장·부구청장 등 직책과 이름을 함께 탐색
- 등록된 공식 인물명·직책·자치구 사전을 이용해 동명이인과 과거 영상을 제외
- 원본 영상, 전체 행사 영상, 재편집 클립을 구분하고 최초 게시자를 추적

### 3단계 · 시민 제보성 공개 영상

- 공개 게시물은 기사가 아니라 취재 신호로만 수집
- 얼굴·계정명·댓글을 불필요하게 복제하지 않고 URL과 검증에 필요한 최소 문맥만 보존
- 비공개 영역, 로그인 우회, 이용약관을 위반하는 수집은 하지 않음

## 발굴 신호

다음 가운데 하나 이상이 있을 때만 심사 후보로 올린다.

1. 공식 설명과 현장 상황의 충돌
2. 예산·일정·안전·권리·접근성에 영향을 주는 예상 밖의 발언
3. 주민·이해관계자와의 물리적 또는 언어적 충돌
4. 기관 간 책임 전가나 서로 다른 설명
5. 정책 변경, 철회, 지연 또는 집행 실패를 시사하는 발언
6. 반복 민원이나 구조적 피해를 보여주는 현장 장면

단순 실언, 무례, 해프닝만으로는 통과시키지 않는다. 시민에게 어떤 손실이 생겼는지, 행정 의사결정이나 책임 구조와 연결되는지를 별도로 확인한다.

## 영상 검증 관문

- 인물·장소·행사·촬영일을 각각 확인
- 짧은 클립 전후 문맥과 가능한 경우 전체 영상을 확보
- 음성·자막을 직접 대조하고 불명확한 표현은 확정 인용하지 않음
- 편집, 재업로드, 배속, 음성 변조 가능성을 표시
- 행사 공지, 회의자료, 보도자료, 현장 참석자 또는 기관 답변 중 하나 이상으로 교차 확인
- 욕설·충돌 장면은 누가 먼저 무엇을 말했는지보다 공적 사안과 시민 영향이 무엇인지 먼저 판정
- 교차 확인 전 단계는 G1 귀속 주장 또는 QUESTION_RAW/VERIFY_TODAY에만 배치

## 예시 적용

“강서구 부구청장이 시민설명회에서 주민과 욕설로 다퉜다”는 제보가 들어온 경우, 문장 자체를 사실로 저장하지 않는다. 다음 질문을 붙인 취재 신호로 처리한다.

- 실제 인물과 행사는 무엇이며 전체 영상에서도 같은 맥락인가?
- 설명회 의제와 주민의 문제 제기는 무엇이었나?
- 충돌 때문에 의견 수렴, 사업 결정, 주민 권리 또는 안전에 영향을 줬나?
- 구청의 공식 설명과 참석자 증언이 일치하나?
- 개인의 부적절한 언행을 넘어 행정의 갈등 조정 실패를 보여주는가?

마지막 질문에 답할 근거가 없으면 사건·논란 단신 후보로 남기고 기획기사 후보로 올리지 않는다.

## 구현 순서

1. 26개 단체장·기관의 공식 계정 등록부를 사람이 검수해 구축
2. 공식 유튜브와 홈페이지 게시물을 먼저 수집해 정확도와 할당량 측정
3. 공직자 등장 영상 탐색을 별도 발견 레인으로 추가
4. 전후 문맥·원본·교차근거가 없는 영상은 자동 보류
5. 2주 그림자 운영에서 적중률, 중복률, 오인률, 검증 소요시간을 측정
6. 플랫폼별 API 비용과 이용약관을 확인한 뒤 SNS 범위를 순차 확대

## 성과 기준

- 공식 인물·행사 오인 0건
- 원본 또는 전체 문맥 확보율 80% 이상
- 수집 신호 중 실제 취재 확인으로 이어진 비율 20% 이상
- 단순 말실수·홍보물·행사 안내가 최종 기획 후보로 통과한 비율 5% 이하
- 시민 영향 또는 행정 책임 질문을 만들 수 없는 신호는 최종 후보 0건
