# Source Scout v1

기존 YouTube 중심 수집이 놓치는 소스를 정식 편입하기 전에, 같은 조건에서 발견력과 수집 부담을 비교하는 시험 모듈입니다.

## 시험 소스

1. 서울시 응답소 공개민원 — 시민 질문과 공식 답변
2. 서울시의회 회의록 — 집행·예산·제도 공백
3. 서울 열린데이터 신규 데이터셋 — 후속 검증 가능한 원자료
4. 고용노동부 임금체불 통계 — 월별 구조 변화와 서울 비교
5. 서울 빅데이터캠퍼스 — 카드소비·생활이동 등 세부 검증 데이터
6. 서울연구원 정책·연구 자료 — 독립 분석과 가설 보강
7. 한국소비자원 피해·분쟁 자료 — 시민 손실 신호와 서울 현지화 후보

## 판정 원칙

- 수집 성공만으로 정식 편입하지 않습니다.
- 사업명·정책 목적·비교 없는 단일 금액은 질문 근거가 아닙니다. 구체 문제 징후 또는 분해 가능한 구조 자료가 있는지 먼저 판정합니다.
- 잠재적 수혜자나 가능한 동선을 실제 피해자·손실로 바꿔 쓰지 않습니다.
- 서울 범위, 문제·변화, 수치·공개근거, 제도·집행, 시민 손실을 합산해 후보를 정렬합니다.
- 행사·축제·공연·모집·홍보성 문구는 감점합니다.
- 같은 원문의 여러 문장은 한 사안으로 합쳐 과대 집계를 막습니다.
- 문제·변화와 수치·공개근거 또는 시민 손실이 함께 있는 서울 사안만 ‘유효후보’로 표시합니다.
- 유효후보 중 8점 이상인 사안만 ‘강한 후보’로 표시합니다.
- 검증 전용 소스는 기사 아이템이 아니라 분석에 쓸 데이터 자산으로 별도 판정합니다.
- 전국 단위 자료는 점수가 높아도 바로 서울 아이템으로 승인하지 않고 ‘서울 현지화 필요’로 분리합니다.

자동 점수는 편집 판단을 대신하지 않습니다. 상위 후보는 질문의 새로움, 반대 근거, 4시간 이내 검증 가능성, 취재원 확보 가능성을 사람이 다시 검토해야 합니다.

## 산출물

- `output/performance_latest.md`: 소스별 성능과 상위 후보
- `output/performance_latest.json`: 전체 측정값과 레코드
- `output/candidates_latest.csv`: 후보 검토표

이번 단계는 시험 전용입니다. 결과를 검토하기 전에는 일일 브리핑 수집원에 자동 편입하지 않습니다.

## 서울시의회 문맥 잠금

서울시의회 회의록의 짧은 수치 문장은 단독 후보로 사용하지 않습니다. 상세 회의록에서 발언자와 구체 사안·대상·업종 범위를 같은 발언 안에서 복원한 뒤에만 질문을 생성합니다.

- context_status=PASS: 발언자와 같은 주제 블록에서 구체 사안·서울 적용 범위·영향 대상을 잠근 단서
- context_status=HOLD: 발언자·대상·서울 범위 또는 정량 수치의 기준기간을 복원하지 못한 단서
- 등록되지 않은 새 의제도 고유 사안명·적용 범위·영향 대상이 모두 원문에 있으면 일반 문맥 규칙으로 통과할 수 있습니다.
- HTML에서 발언자·직책이 여러 조각으로 나뉘어도 다시 묶되, 다른 화자와 '다음은·둘째·끝으로' 같은 주제 전환은 넘지 않습니다.
- 의원 발언의 수치는 '발언에서 제시된 내용'과 '산정 원자료 미확인'으로 표시합니다. 문서일과 수치 기준기간은 분리하며, 기간이 없으면 질문을 만들지 않습니다.
- 문맥이 보강되면 후보 ID는 유지하지만 원문 revision은 바뀌어 과거 사람 판정을 자동 승계하지 않습니다.
- 복합 금액은 '1조 9,860억 원', '1억 4,000만 원'처럼 하나의 측정값으로 보존합니다.


## 편집 판정 대기 기간

오늘 처음 발견한 새 원문이 다음 날 재등장하지 않아도, 사람이 판정하지 않았고 출처 날짜·신선도·질문 근거(시의회는 발언 문맥까지)가 확인된 경우에만 최초 발견일부터 최대 7일간 편집 판정 카드에 남깁니다. 이 기간은 **검토 접근성**을 위한 것이며 오늘 새 신호로 재분류하거나 신선도를 연장하지 않습니다. 판정 완료·기간 만료 항목은 과거 이력을 보존하되 미판정 카드에서 제외합니다. 같은 출처에서 동일한 사안과 질문이 URL만 달리해 반복되면 검토 화면에는 한 카드만 보여주고 원래 대기열의 수집 이력은 유지합니다. 서울 지역화 대기·문맥 보류 항목을 자동 승격하지 않으며, 편집자의 확인 없이 기사 장부를 변경하지 않습니다.

## 문맥 HOLD 편집 검토 자동 선별

사람이 고른 단서만 매일 보여주는 것은 발굴 시스템의 성능을 개선하지 않습니다. 수집기가 문맥 HOLD를 유지하되, **정확한 사안·서울 범위·영향 대상이 확인되고 빠진 항목이 수치 기준기간뿐**이며 구체적인 문제·손실 표현이 있는 신선한 시의회 발언은 별도 `editorial_triage`로 최대 5건 선별합니다. 자동 점수는 선별 보조 조건이지 편집 승인 점수가 아닙니다.

- 이 영역은 **사안의 취재 가치에 대한 사람 판단 대기**이며, 수치·피해 확정, 질문 품질 PASS, S0 전이, 기사 후보가 아닙니다.
- 정확한 사안이나 서울 적용 범위가 비어 있거나 피해 표현이 추상적인 발언은 기존 문맥 확인 대기에 남깁니다.
- 기존 편집자 지정 3건은 자동 선별 결과와 대조하는 회귀 사례로 사용합니다. 새 사안을 이 3건의 키워드에만 맞춰 선별하지 않습니다.
- 원문 수치의 기준기간이 확인되거나 독립 자료가 추가되면 기존 문맥·질문·기사 게이트에서 다시 평가합니다. 자동 선별 상태만으로 장부를 바꾸지 않습니다.
