# Source Scout v1

기존 YouTube 중심 수집이 놓치는 소스를 정식 편입하기 전에, 같은 조건에서 발견력과 수집 부담을 비교하는 시험 모듈입니다.

## 시험 소스

1. 서울시 응답소 공개민원 — 시민 질문과 공식 답변
2. 서울시의회 회의록 — 집행·예산·제도 공백
3. 서울 열린데이터 신규 데이터셋 — 후속 검증 가능한 원자료
4. 고용노동부 임금체불 통계 — 월별 구조 변화와 서울 비교
5. 한국소비자원 피해·분쟁 자료 — 시민 손실 신호와 서울 현지화 후보

## 판정 원칙

- 수집 성공만으로 정식 편입하지 않습니다.
- 서울 범위, 문제·변화, 수치·공개근거, 제도·집행, 시민 손실을 합산해 후보를 정렬합니다.
- 행사·축제·공연·모집·홍보성 문구는 감점합니다.
- 5점 이상이며 서울 범위가 확인된 문구를 ‘유효후보’로 표시합니다.
- 7점 이상이며 서울 범위가 확인된 문구를 ‘강한 후보’로 표시합니다.
- 전국 단위 자료는 점수가 높아도 바로 서울 아이템으로 승인하지 않고 ‘서울 현지화 필요’로 분리합니다.

자동 점수는 편집 판단을 대신하지 않습니다. 상위 후보는 질문의 새로움, 반대 근거, 4시간 이내 검증 가능성, 취재원 확보 가능성을 사람이 다시 검토해야 합니다.

## 산출물

- `output/performance_latest.md`: 소스별 성능과 상위 후보
- `output/performance_latest.json`: 전체 측정값과 레코드
- `output/candidates_latest.csv`: 후보 검토표

이번 단계는 시험 전용입니다. 결과를 검토하기 전에는 일일 브리핑 수집원에 자동 편입하지 않습니다.
