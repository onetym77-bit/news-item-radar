## 핵심 결론

**이번에는 자료 공급 부족 외에 수집 경로의 문제가 확인됐다.** 웹 읽기에 표시된 시민제안은 9월 7일 자료였지만, 같은 목록을 GitHub 실행 환경에서 직접 요청하자 9월 14일 자료가 보였다. 응답소도 캐시의 9월 11일 기준값과 직접 요청의 9월 14일 기준값이 달랐다. 따라서 검색·웹 읽기 실패를 원사이트의 자료 부재로 처리해서는 안 된다. 다만 이 시험만으로 기존 일일 브리핑의 모든 무발굴 원인을 설명할 수는 없다.

**자료를 읽는 것과 좋은 질문을 얻는 것은 별개의 성능이다.** 고정 표본에서 천왕산 책쉼터의 무장애 공사가 후속 확인 가치가 가장 높았다. 그러나 기존 접근 장벽이나 시민 손실은 확인되지 않았고, 최소 검증에 필요한 공사 상세도 확보하지 못했다. 질문 구조를 통과하더라도 곧바로 기사·우선 검증 단계로 올리지 않는다.

신규 핵심 소스 승격 0, 기사 전환 0, 아이템 장부 등록 0. 이는 모든 질문을 기각했다는 뜻이 아니라, 현재 확보한 근거와 준비도를 넘어서 통과시키지 않았다는 뜻이다.

## 1. 표본과 실제 접근 결과

접속 시험은 7개 URL, 편집 시험은 7개 자료다. 서로 다른 단위다.

- 편집 표본: 통계 화면 E1 + 계약 C1~C3 + 시민제안 P1~P3.
- 계약·제안은 최초 웹 읽기의 상위 3건을 고정했다. 직접 요청에서 더 최신 자료가 확인돼도 편집 표본은 바꾸지 않았다.
- 계약 지급 3행은 중복·날짜 해석을 위한 보조 점검이다.
- 전체 본문 파서, 원계약·변경계약 연결, 반복 관측 성공률은 이번 시험 범위 밖이다.

## 3. 실제 질문과 첫 확인

### C1 — 먼저 보강할 질문

**무장애 공사를 하는 천왕산 책쉼터에서, 이동이 불편한 주민의 이용 기회를 가르는 것은 시설 내부인가, 그곳까지 이어지는 진입 동선인가? 이번 공사 범위는 실제 장벽과 맞는가?**

- 관찰: 기존 운영 시설의 무장애 공사가 새로 등록됐다. [구로구의 2022년 개관 자료](https://www.guro.go.kr/www/selectBbsNttView.do?bbsNo=665&key=1793&nttNo=123738&pageIndex=3&pageUnit=10)에서 당시 운영 개시를 확인했다.
- 시민 이해관계 가설: 휠체어·보행보조기 이용자의 우회·동행 의존·방문 포기. 실제 손실을 관찰한 것은 아니다.
- 경쟁 설명 A: 기존의 물리적 접근 장벽을 이번에 해소하는 공사다.
- 경쟁 설명 B: 이미 이용 가능한 시설의 추가 개선·유지관리 또는 기준 대응이다. 기존 배제를 전제하면 잘못된 기사가 될 수 있다.
- 구분 변수: 이동 능력 × 동선 구간(진입로/건물 내부), 공사 전후의 독립 이동 가능 여부와 우회 시간, 공사 범위 및 발주 이유.
- 출처에서 더한 질문: 공사 필요성을 비판하는 데 그치지 않고, 이용 동선의 어느 구간에서 누가 혜택을 얻거나 빠지는지 확인한다.

**실제로 한 첫 확인:** 2022년 개관 사실과 2026년 공사 등록을 대조했다. 여기까지는 확인됐다. 그러나 원계약 상세·도면·발주 사유·현재 동선을 확보하지 못해 접근성 가설 자체를 판정하지는 못했다.

**다음 최소 확인:** 공사 범위와 해당 구간의 현재 접근 조건을 먼저 확보한다. 자료가 없으면 구로구 담당 부서 확인·현장 점검이 필요한 취재 메모로 남긴다. 실제 문의·방문은 하지 않았다.

- 후속 기사 검토: 특정 이용자의 동선 단절이 확인되고, 공사 범위에서 그 장벽이 빠진 이유까지 확인될 때.
- 축소: 장벽은 있었지만 이번 공사가 실질적으로 해소한다면 이용 개선과 남은 과제를 다루는 점검으로 좁힌다.
- 폐기: 기존 이용 배제가 없고 개선 목적·범위가 현장 조건과 맞는다면 ‘오래 방치된 접근 장벽’ 가설을 접는다.

점수 순서: 긴장 1 / 시민 손실 1 / 분포·배제 2 / 경쟁 가설 2 / 책임 1 / 반증 2 = **9/12, 질문 구조 PASS**. 분포는 이동 능력과 동선 구간의 두 축이다. 손실은 가설뿐이므로 1점, 구체 발주 결정의 이유를 모르므로 책임도 1점이다.

**신규성 HOLD / 최소 판정 실험 HOLD / 기사 미통과.** 제한된 선행 검색으로 독창성을 입증하지 못했다. 휠체어 이동을 언급한 다른 시설의 설계자 인터뷰는 해당 대목이 천왕산이 아니라 강감찬도시농업센터 설명이어서 근거에서 제외했다. 2022년 개관 자료도 접근 장벽의 증거로 사용하지 않는다.

### E1 — 질문보다 집계 범위 확인이 먼저

**민원 건수를 생활불편 우선순위로 삼으면, 신고하기 쉬운 문제에 대응이 몰리고 온라인 신고가 어려운 고령층 등의 수요가 덜 반영되는가?**

- 가설 A: 신고 경로·반복 신고·신고 용이성이 분포를 만든다.
- 가설 B: 실제 이용량과 불편 발생량의 차이가 분포를 만든다.
- 구분 자료: 같은 기간·분야의 신고 정의, 중복 처리 기준, 이용량 및 실제 대응 결과. 현재 화면에 없는 교차표를 만들어낸 것으로 취급하지 않는다.
- 실제 첫 확인: 9/11 기준 화면의 일별·채널별·분야별·기관별 합계가 각각 256,488건이었다. **25개 구 합계 221,943건은 전체가 아니라 ‘자치구’ 처리기관 합계와 일치했다.** 이를 곧바로 서울 전체 민원의 거주지별 분포로 해석할 수 없다. 공식 집계 정의는 추가 확인이 필요하다.
- [공식 처리 절차](https://eungdapso.seoul.go.kr/not/guide/process_guide.do)는 처리기관 배정과 공개사례의 선별 조건을 설명한다. 공개 게시판의 적은 사례 수만으로 민원 발생량을 판단하지 않는다.

모든 항목 1점 = **6/12, HOLD**. 실제 행정 우선순위가 이 통계로 정해지는지도 미확인이다. 비교 가능한 자료가 없어 이번에는 분포 질문을 기사 후보로 승격하지 않는다. 반복 신고·구성 차이로 충분히 설명되면 구조적 배제 가설을 접는다. 신규성·최소 검증도 HOLD다.

### P3 — 행사 소재도 질문할 수 있지만 기존 보도의 반복은 피한다

**장시간 기다릴 수 없는 방문자의 공원 이용 기회를 줄이는 것은 무인 물품 점유를 관리하는 방식인가, 한정된 공간에 몰리는 실제 수요인가?**

- 가설 A: 사람이 없는 물품의 장시간 점유가 이용 기회를 막는다.
- 가설 B: 실제 방문객 수요와 공간 용량이 주된 원인이다.
- 구분 변수: 동일 장소·시간의 유인/무인 점유 면적·지속시간, 뒤늦게 온 방문자의 이용 포기 및 이동 부담.
- 실제 첫 확인: [서울시 한강공원 안내](https://hangang.seoul.go.kr/www/bbsPost/17/632/detail.do?mid=604&tr_code=sweb)에서 일반 돗자리 이용과 그늘막 설치 기준이 다름을 확인했다. 무인 점유 허용 여부나 특정 축제의 운영 기준까지 확인한 것은 아니다.
- 신규성 확인: 9/4자 [선행 보도 검색 결과](https://nongmin.com/article/20260904500272)에 이미 무인 자리 점유·회수 문제가 등장했다. 해당 기사의 원문 재열기는 실패했으므로 세부 사실의 근거로 사용하지 않는다. 이 정도 확인으로는 새 질문이라고 통과시킬 수 없다.

긴장 1 / 시민 손실 1 / 분포 1 / 경쟁 가설 2 / 책임 1 / 반증 1 = **7/12, HOLD**. 실제 점유 및 이용 포기 관찰이 필요하다. 무인 점유가 작거나 이용 제한이 실제 밀집으로 설명되면 관리 실패 가설을 접는다. 제안자의 시설 설치 해법을 편집부의 대책으로 채택하지 않는다.
