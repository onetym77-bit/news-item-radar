# 서울 기획기사 데일리 브리핑 v4 — 편집 게이트

## 목적

하루에 수집된 관심·구조 신호 중, 서울 시민에게 실제 장면이 있고 공공데이터·현장 취재로 검증 가능한 기획기사 가설만 최대 3건 제시한다.

## 입력

1. 관심 레이더 v2의 원천 신호
2. 구조 레이더의 축적 관찰(S1·S2)
3. 당일 현장 단서 또는 편집자가 보유한 취재 맥락

정책 발표·보도자료·법 개정도 수치·결과·변화를 분해할 수 있으면 질문의 출발점으로 쓸 수 있다. 발표의 설명과 자기평가를 기사 결론으로 옮기지는 않는다.

## 통과 질문

### 0단계 A: 질문 품질 게이트

세 진입 조건인 객관적 현상, 시민 이해관계, 검증 경로가 모두 있어야 한다. 이후 `agent-system-v1/QUESTION_QUALITY_GATE.md`에 따라 긴장·반전, 시민 손실·권리, 분포·배제, 경쟁 가설, 책임·변경 가능성, 반증·판정선을 각 0~2점으로 평가한다.

12점 중 8점 이상이며 시민 손실·권리, 경쟁 가설, 반증·판정선이 각각 1점 이상일 때만 PASS다. PASS 원석은 중심 질문 한 개, 경쟁 가설 두 개 이상, 가설을 가를 변수, 기사 전환·축소·폐기 판정선을 적은 뒤 우선순위 2~4건을 실제 검증한다.

“어디에 집중됐나”, “지역별로 다른가”, “실제로 불편한가”만 묻거나 규범적 판단 기준 없이 “공정한가·자연스러운가”를 묻는 질문은 HOLD 이하로 둔다.

### 0단계 B: 독창성·최소 검증 게이트

질문 품질 PASS마다 출처 프레임과 편집적 추가를 분리하고, 같은 중심 질문의 선행보도를 확인한다. `agent-system-v1/ORIGINALITY_AND_TEST_GATE.md`에 따라 독창성 PASS이며 24시간 이내 최소 판정 실험이 있을 때만 우선 검증한다. 우선 검증에서는 시민 손실 근거와 반대 근거를 모두 찾는다.

### 0단계 C: 기사 게이트

검증 결과 의미 있는 집중·격차·불일치·예상 밖의 결과가 확인되고, 영향 집단·규모·지속성·분배·원인·책임 주체·반증 조건을 설명할 수 있어야 PASS다. 기사 게이트 PASS만 S2 이상으로 올린다.

각 소재는 아래 다섯 질문에 답해야 한다.

| 질문 | 통과 기준 |
|---|---|
| 시민 장면 | 실제로 관찰됐거나 당사자가 진술한 서울 시민의 행동이 있는가. 취재 예정 장면은 별도로 표시했는가 |
| 새로움 | 이미 보도된 정책 설명이 아니라 새 변화·모순·격차가 있는가 |
| 서울성 | 서울의 특정 생활권·집단·인프라와 연결되는가 |
| 데이터성 | 공개 데이터로 규모·분포·변화를 반증하거나 확인할 수 있는가 |
| 실행성 | 1차 현장 위치·관찰법·인터뷰 실패 대안이 있는가 |

## 탈락 규칙

- “서울시가 무엇을 했다”로만 시작하는 아이템
- 데이터가 숫자 하나뿐이고 시민 장면이 없는 아이템
- SNS 단일 영상, 단일 게시물, 단일 사건만 근거인 아이템
- 실명 섭외가 실패하면 검증 자체가 불가능한 아이템
- 지난 브리핑의 금지·중복 주제
- 공연·축제·팝업·티켓·관광·예약 중 일정·가격·이용 팁 이상의 검증 질문이 없는 소재
- 가격 상승·대기·매진·검색량 자체가 결론인 생활정보형 아이템

## 등급

- **S0**: 원천 신호. 기록만 함.
- **S1**: 한 데이터 레이어에서 관찰된 변화. 기사 후보 아님.
- **S2**: 질문 게이트와 기사 게이트 PASS, 독립 근거 계보 두 개 이상, 관찰 또는 당사자 진술 상태의 시민 영향, 반증 가능한 구조 검증이 교차. 브리핑 검토 가능.
- **S3**: 장소·검증 데이터·취재 접근법이 확보. 편집회의 제안 가능.

## 출력 규칙

- 최대 3건. 통과한 소재가 없으면 `오늘은 확정 후보 없음`을 출력한다.
- S0·S1은 메인 3건에 넣지 않는다.
- 각 후보는 제목보다 먼저 ‘시민 장면’을 한 문장으로 쓴다.
- 데이터는 결론이 아니라 확인해야 할 질문으로 표현한다.
- S2 이상은 근거 계보 표와 시민 장면 상태를 표시한다.
