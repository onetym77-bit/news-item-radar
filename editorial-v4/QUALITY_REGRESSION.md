# 기획 질문 품질 회귀 사례

이 문서는 실제 회차 검토 때 확인할 편집 품질 기준이다. 아래 예시는 편집 판단 시나리오이며, 사례 속 주장 자체를 검증된 사실로 취급하지 않는다. 자동화 단위 테스트는 형식·실행 안전성을 확인하고, 이 문서의 의미 판정은 사람 평가와 실제 모델 실행으로 별도 확인한다.

| 사례 | 기대 판정 | 확인할 차이 |
|---|---|---|
| 버스 파업 과정에서 제기된 통상임금 발언 | 범위를 잠근 질문만 검토 | 서울 전체 임금 시장의 일반 현상으로 확대하지 않음 |
| 기관이 민원 처리 성과를 소개하는 홍보성 기사 | 보류 | 홍보 문구나 민원 건수를 시민 피해·미해결 사건으로 바꾸지 않음 |
| 신규 청년 AI 지원사업에 관한 의원 질문 | 조건부 검토 가능 | 이용 통계가 아직 없다는 이유만으로 폐기하지 않음. 실제 선택과 지원 방식의 갈림길을 묻고 확인 경로를 밝힘 |
| 한 지역의 학교·필수시설 입지 갈등 | 서울 전체로 확장하는 가설 검토 가능 | 한 사건을 곧바로 서울 전역의 님비 현상으로 확정하지 않음. 유사 입지·반대 이유·대체 부지의 비교와 반례를 찾음 |
| 예산 집행률 저조·다음 연도 항목 부재 | 반대 설명이 없으면 보류 | 사업 실패·중단으로 단정하지 않고 이월·회계 항목 변경·집행 시차를 가를 자료를 지정함 |
| 실행일 이후 날짜의 회의·발표 서술 | 보류 또는 향후 계획으로 표시 | 미래 사건을 이미 일어난 일로 표현하지 않음 |

실제 회차의 평가는 최소한 다음을 나눠 기록한다.

1. 입력 단위: 원자료 본문 여부, 출처군, 문서일, 직접 시민 신호 여부.
2. 1차 제안: 제목·주제·두 질문의 역할 중복, 사안별 갈림길, 사실 단정.
3. 2차 반론: 가장 큰 오판 위험, 반대 설명, 결정적 검증, 6~7분 방송 장면.
4. 최종 사람 판정: 실제 취재 착수 가치, 기존 보도와 달라진 **질문**, 보류 이유.

2~3건은 목표이고 할당량이 아니다. 0건도 기록하며 소스 연결 실패와 품질 탈락을 구별한다. 뉴스 조회·검색량은 관심의 보조 지표이고 시민 경험의 독립 확인을 대체하지 않는다.
