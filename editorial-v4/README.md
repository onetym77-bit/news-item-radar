# 월·수 기획 질문 검토 v4

목표: 서울시민 대상 6~7분 방송 기획 리포트로 확장 가능한 새 질문을 매주 월·수 오전 검토한다. **2~3건은 목표이지 할당량이 아니다.** 질문의 가치가 없으면 0건이다.

```text
08:00 공개 소스 피드 ─┐
08:30 뉴스 관심·본문 판정 ─┼─> 본문·맥락 단위 입력 (최대 8건)
최근 감사 결과 카드 ────┘                  │
                                     기존 선정·판정 제외
                                            │
                                     한 번의 모델 평가
                                            │
                          인용·질문·반대설명·취재경로 검사
                                            │
                             출처군·사안 중복 제거, 최대 3건
                                            │
                              화면: 기획 질문 검토안(미검증)
                                            │
                              사람: 완료·기각·보류 기록
```

| 단계 | 담당/작동 | 생성하지 않는 것 |
|---|---|---|
| 공개 소스 입력 | 서울시의회 발언의 짧은 근거·문맥, 뉴스 본문 판정의 파생 요약, 감사 지적 확인 카드만 읽음 | 원문 전체 저장, 목록만으로 후보 작성 |
| 사전 제외 | 기존 편집자 선정 발언과 이미 판정한 ID 제외 | 이전 주제의 무단 재포장 |
| 질문 제안 | 서울 시민의 선택·불편·형평성에 대한 사안별 질문, 덜 당연한 질문, 반대 설명, 첫 취재 대상과 장면 제안 | 주장이나 검색어를 확인된 피해로 단정 |
| 기계 검사 | 실제 입력에 있는 연속 인용, 구체적 제목·질문·취재 경로 확인 | 범용 질문, 원문 복사 제목, 억지 3건 |
| 화면/사람 판정 | 검토안과 최종 승인 후보 분리; 정확한 ID에 완료·기각·보류 기록 | 자동 기사 승인, 자동 사실 확정 |

## 현재 연결 경계

- 서울시의회: 파생 발언 문맥 가능. 같은 회의록 URL에 여러 발언이 있어 URL만으로 중복 판정하지 않는다.
- 뉴스: 본문을 읽고 내용 유형을 판정한 항목만 사용. 기사 내용은 독립 검증 전이다.
- 서울시 감사: 최신 3건에 실제 지적 내용이 확인된 경우만 사용. 최근 표본 모두 보류라면 0건이 정상이다.
- 25개 구의회: 목록 연결·변화 관측까지만 됐다. 회의록 발언 본문은 아직 통합되지 않았다.
- 유튜브: 검색 질의 건강 상태가 저장될 뿐 영상별 발언 맥락이 없다.
- 지역 커뮤니티·제보: 공개 본문이나 제보 수신 경로 미연결.
- 검색 관심도: 시민 관심의 보조 단서이지 단독 기획 사안이 아니다.
- 단체장 SNS: 계정 주소 L0 수준이며 게시물 본문 연결 전. 현재 기획 입력에서 제외.

## 운영

`Collect interest signals` 성공 뒤 자동 실행. 수동 실행도 가능하며 OpenAI API 비용은 실행당 최대 한 번의 모델 호출에 한정한다. PR은 모델을 호출하지 않고 테스트와 입력 매핑 드라이런만 한다. 모델 불완전 응답이나 API 실패 시 이전 결과를 새 결과로 위장하지 않고 워크플로우가 실패한다.

화면의 '판정 ID'를 `Review editorial v4 proposal` 워크플로우에 넣어 COMPLETE(취재 검토 완료), DISCARD(기각), HOLD(보류)를 기록한다. 판정 이력은 별도 파일에 남고 다음 화면 갱신에서 대기 카드에서 빠진다. COMPLETE도 기사 승인·사실 확정은 아니다.

## 남은 통합 순서

1. 구의회 25곳의 본문/발언 단위 확보 및 날짜·화자·안건 검증. 노이즈 2곳을 목록만 보고 억지 연결하지 않는다.
2. 유튜브 개별 영상의 제목·게시일·발언 자막/설명과 원본 URL, 지역성 확인. 검색 질의 통계만으로 제안하지 않는다.
3. 시민 제보·커뮤니티의 접근 가능한 공개 본문, 개인정보 제거, 중복·홍보성 판정 경로 확보.
4. 실제 월·수 회차의 사람 평가로 유효질문율·반복률·출처 편중을 측정하고 질문 프롬프트와 소스 순서를 조정한다.

현 단계는 완전한 소스 통합이 아니다. 화면에 각 누락 이유를 표시해 빈 소스를 정상 0건과 혼동하지 않는다.
