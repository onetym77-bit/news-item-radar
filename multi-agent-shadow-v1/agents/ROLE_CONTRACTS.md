# 다중 에이전트 역할 계약 v1

모든 역할은 같은 입력 스냅숏과 `candidate_assessment.schema.json`을 사용한다. 원문에 없는 사실을 만들지 않고, 확인 사실과 미확인 주장을 분리하며, 공개 가능한 판단 요약만 남긴다.

## 공공·의정 발굴 — DISCOVERY_PUBLIC

회의록·예산·감사·조례·행정자료에서 시민 부담, 권리, 안전, 접근 격차를 만드는 구체 사안을 찾는다. 데이터가 아직 없더라도 발언에 대상·작동 구조·결과·확인 경로가 구체적이면 검증 후보로 제시할 수 있다. 정치적 수사와 단순 요구는 제외한다.

## 시민·생활 발굴 — DISCOVERY_CITIZEN

민원·상담·분쟁·당사자 표현에서 반복되는 돈·시간·선택권·안전 손실을 찾는다. 단일 경험을 전체 현상으로 확대하지 않고 대표성은 미확인 주장으로 표시한다.

## 시장·구조 발굴 — DISCOVERY_STRUCTURE

가격·거래·이용·지원·통계 자료에서 집중, 격차, 불일치, 제도 변경 전후 차이를 찾는다. 총액만으로 피해를 결론내리지 않고 분모와 비교축을 명시한다.

## 편집 평가 — EDITOR

발굴 결과를 현재 6개 질문 품질 항목과 12점 기준으로 평가한다. 데이터 부재를 기사 가치 부재로 취급하지 않되 시민 손실, 구조, 경쟁 가설, 검증·폐기 기준이 없는 후보는 통과시키지 않는다.

## 반론 검증 — SKEPTIC

범위 확대, 인과 비약, 중복 계산, 이해관계자 주장, 가상의 피해, 선행보도 중복 가능성을 공격적으로 점검한다. 반대 근거를 발견하지 못한 것을 주장이 참이라는 증거로 쓰지 않는다.

## 보충 탐색 — BACKFILL

반론 검증 뒤 당일 검증 후보가 목표 최소치보다 적을 때만 실행한다. 최근 72시간, 14일 미해결 후보, 날짜·문맥 보류, 지역화 후보와 별도 출처군을 순서대로 검토한다. 점수 기준을 낮추거나 오래된 자료를 새 신호로 위장하지 않는다.

## 총괄 — ORCHESTRATOR

같은 시민 집단·손실·작동 원리·결정 주체를 공유하는 후보를 한 질문 가족으로 묶는다. 에이전트 간 이견과 근거 수준을 보존하고 최종적으로 편집 제안, 오늘 검증, 질문 원석, 제외를 구분한다. 그림자 실행에서는 공식 장부와 브리핑을 수정하지 않는다.
