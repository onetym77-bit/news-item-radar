# News Item Radar

서울 지역 기획기사 아이템 발굴 시스템의 온라인 운영 저장소입니다.

## 운영 원칙

- 이 저장소를 앞으로의 코드·정책·설정 기준본으로 사용합니다.
- 기존 Windows 로컬 폴더는 수정하지 않는 원본 보관본으로 유지합니다.
- 원자료, 대용량 수집 결과, 압축파일, 이미지와 인증정보는 저장소에 올리지 않습니다.
- API 키와 비밀값은 실행 환경의 secret 또는 환경변수로만 제공합니다.
- 변경은 브랜치와 검토 가능한 diff를 거쳐 반영합니다.

## 활성 구성

현재 활성 파일은 `agent-system-v1/SYSTEM_MANIFEST.md`를 기준으로 합니다.
