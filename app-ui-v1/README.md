# 앱 UI v1 — 읽기 전용 운영 화면

## 목표

수집·판정 로직과 분리된 화면에서 실행 상태, 소스 성숙도, 사람 판정 대기 카드와 최신 브리핑을 한눈에 확인한다.

## 설계 원칙

1. 화면은 읽기 전용이며 장부·브리핑을 직접 수정하지 않는다.
2. 접속 실패와 실제 0건을 서로 다른 상태로 표시한다.
3. L0~L2 자료는 아이템 후보로 승격해 보이지 않는다.
4. 각 수치에는 실행 시각과 출처 링크를 함께 표시한다.
5. 데이터가 없을 때는 빈 화면 대신 샘플·미수집·접속 실패 상태를 표시한다.

## 현재 구현

- 정적 HTML/CSS/JavaScript 화면
- `data/latest.json` 형식의 정규화된 데이터 계약
- 실제 데이터 파일이 없거나 읽히지 않으면 샘플 데이터로 자동 전환
- 화면 상단에 `실제 산출물` 또는 `샘플 화면` 상태 표시

`data/latest.json`은 GitHub Actions가 생성하는 읽기 전용 산출물입니다. 뉴스 탐색 신호와 별도로 시의회·응답소 등 일일 피드, 자치구의회 목록 관측, 감사 그림자 평가, 유튜브 검색 시험의 최근 저장 상태를 `sourceExploration`에 정규화합니다. 이 단서는 최종 편집 후보로 자동 승격되지 않습니다. 원자료 수집 실패와 0건을 구분하고, 목록 관측·그림자 평가·본문 판정의 단계를 명시합니다.
