# 서울시장·25개 구청장 SNS: 넓고 얇은 L0 연결

26개 행정 단위(서울시 + 25개 자치구)의 홈페이지를 등록했다. 서울시 공식 목록에 직접 연결된 기관 계정 3개와, 편집자가 2026-09-18 제공·확인한 단체장 페이스북 계정 26개를 **서로 다른 근거 유형**으로 기록한다.

## 계정 확인 수준

- 기관 계정 3개(서울시 유튜브·인스타그램·블로그): 서울시 [공식 SNS 목록](https://mediahub.seoul.go.kr/staticpage/sns.do)의 직접 링크를 근거로 등록했다. 검증기는 이 목록의 링크 존재 여부만 재확인한다.
- 단체장 페이스북 계정 26개: `editor_confirmed_officeholders.json`에 편집자 제공 목록을 보존하고 `accounts.json`에 `EDITOR_ATTESTED`로 등록했다. 이는 검색 결과를 자동 승인한 것이 아니며, 이 코드가 페이스북 프로필의 본인성·최근 활동을 독립적으로 재확인했다는 뜻도 아니다.
- 25개 구청 홈페이지: [정부24 지자체 누리집 목록](https://www.gov.kr/portal/orgSite?pageIndex=1&srchOrgCd=3200000)을 근거로 등록했다. 홈페이지 확인은 구청 기관 SNS 계정 확인과 별개다. 구청 기관 계정은 아직 등록하지 않았다.
- `facebook.com/profile.php?id=...` 형식의 두 계정은 숫자 ID까지 계정 키에 포함한다. 쿼리를 버려 서로 같은 계정으로 취급하지 않는다.

`CONFIRMED_LISTED`는 공식 목록에 동일 링크가 있다는 뜻이며 콘텐츠 진위까지 보증하지 않는다. `EDITOR_ATTESTED_NOT_PLATFORM_RECHECKED`는 편집자 확인 목록에 등록됐으나 플랫폼 현황을 이 실행에서 다시 확인하지 않았다는 뜻이다. `SOURCE_UNAVAILABLE`은 공식 목록 접근 실패이지 계정 부재가 아니다.

## 검색 경로와 분리

`name_search_seeds.json`의 26명 이름은 편집자 확인 명부와 일치한다. `search_officeholder_names.py`는 네이버 웹문서 검색으로 새로운 페이스북 URL 후보를 찾지만, 그 결과는 계속 **미승인 후보**다. 이미 등록된 URL과 일치하더라도 검색 결과 자체가 추가적인 본인성 증거는 아니다. 검색당 첫 5결과, 행정 단위당 최대 3후보로 제한한다.

수동·PR 읽기 전용 계정 점검은 `.github/workflows/official-social-l0.yml`, 이름 검색은 `.github/workflows/officeholder-name-search-l0.yml`에서 실행한다. 프로필·게시물 수집, 질문 생성, 일일 브리핑 및 장부 연결은 아직 하지 않는다.

다음 단계는 등록한 계정의 접근 가능성·게시일·고유주소 등 L1 목록 표본을 제한적으로 시험하고, 기술적 성공과 편집상 유용성을 분리해 평가하는 것이다. 외부 출연 영상과 시민 촬영 콘텐츠는 공식 계정 레인에 섞지 않는다.

## 게시물 목록 접근 가능성 시험

`probe_post_index.py`는 등록된 26개 계정을 대상으로 네이버 웹문서 검색을 계정당 1회만 수행한다. 검색 결과 중 등록된 계정 경로와 엄격히 일치하는 `/posts/` 또는 숫자 ID의 `permalink.php` 주소 후보를 최대 3개만 기록한다. 페이스북 프로필·게시물에는 요청하지 않고 제목·본문·설명도 저장하지 않는다.

검색 색인 주소는 게시물의 실제 작성자·게시일을 검증하지 못한다. 주소를 찾더라도 L1 통과로 간주하지 않으며 `official_sns_network` 성숙도는 L0으로 둔다. 못 찾았을 때도 게시물 0건이나 계정 미활동으로 해석하지 않는다. 이 시험은 `.github/workflows/officeholder-post-index-feasibility.yml`에서 PR에는 키 없이, main 변경·수동 실행에는 기존 네이버 검색 키로 읽기 전용 실행한다. 결과는 7일 artifact로만 보관한다.

## 공식 홈페이지 연결 유튜브 피드 8곳 얇은 시험

홈페이지 L0 결과에서 고유 채널 ID가 직접 확인된 관악·노원·마포·종로·용산·구로·금천·동작 8곳을 `youtube_feed_trial.json`에 후보로 고정했다. 이는 단체장 개인 계정 26개와 다른 **구청 홈페이지 연결 채널**이며, 링크 존재를 채널 주체·편집 가치의 최종 승인으로 해석하지 않는다.

`collect_youtube_feed_trial.py`는 [YouTube가 문서화한 공개 Atom 피드](https://developers.google.com/youtube/v3/guides/push_notifications)에서 채널 ID를 대조하고 영상 제목·게시일·고유주소만 최대 20건 읽는다. 설명·본문·댓글·조회수는 받지 않으며, 실패는 영상 0건으로 처리하지 않는다. PR은 네트워크 없이 검증하고 main 변경·수동 실행만 읽기 전용 표본을 얻는다. 결과는 7일 artifact에만 보관한다. 소스 성숙도는 사람의 채널 주체·메타데이터·편집 가치 검토 전까지 L0이다.
