# 서울시장·25개 구청장 SNS: 넓고 얇은 L0 연결

현재 범위는 **계정 공식성의 확인**이다. 26개 행정 단위(서울시 + 25개 자치구)를 모두 등록했지만, 26명의 단체장 개인 계정이나 25개 구청 계정을 확인했다는 뜻은 아니다.

## 이번 연결 범위

- 서울시가 직접 공개한 [공식 소셜 미디어 목록](https://mediahub.seoul.go.kr/staticpage/sns.do)에 연결된 서울시 대표 유튜브·인스타그램·블로그 3개를 **기관 계정**으로 등록했다.
- 자치구 25곳은 누락을 추적할 수 있는 등록 슬롯만 마련했다. 홈페이지와 계정 URL은 공식 페이지의 직접 링크를 확인하기 전까지 비워 둔다.
- 서울시장·구청장 **개인 또는 직책 계정**은 기관 계정과 분리한다. 이름 검색 결과나 영상 출연만으로 공식 계정으로 인정하지 않는다.
- 검증기는 SNS 게시물이나 프로필을 접속·수집하지 않고, 공식 목록 페이지가 해당 계정 링크를 여전히 게재하는지만 확인한다.

## 판정 해석

- `CONFIRMED_LISTED`: 공식 목록 페이지에 같은 계정 링크가 확인됨. 계정 내용의 진위나 최근 활동을 뜻하지 않는다.
- `NOT_LISTED_NEEDS_REVIEW`: 목록 페이지는 열렸지만 링크가 보이지 않음. 삭제·비공식 판정이 아니라 재검토 대상이다.
- `SOURCE_UNAVAILABLE`: 공식 목록 접근 실패. 계정이나 게시물이 없다는 뜻이 아니다.
- 미등록: 공식 URL 확인 전 상태. 계정이 실제로 없다는 뜻이 아니다.

## 다음 공통 작업

1. 서울시 또는 각 구청 공식 홈페이지의 SNS 안내·푸터에서 구청 기관 계정 URL과 이를 가리키는 공식 페이지 URL을 함께 등록한다.
2. 구청장 개인 계정은 구청 공식 페이지에서 직접 연결되거나 공적 인증 근거가 있는 경우에만 별도 등록한다.
3. 26개 단위의 공식 링크 확인률과 기술 접속률을 먼저 산출한다. 미등록/접속 실패는 0건 성과로 처리하지 않는다.
4. 공식 유튜브·홈페이지에 한해 L1 목록 20건 이내 표본으로 넘어간다. 게시일·고유주소·원계정 여부만 확인하고, 유망 소스를 선별하기 전 질문 생성은 하지 않는다.
5. 외부 출연 콘텐츠·시민 촬영 영상은 별도 레인으로 두고, 공식 계정 확인과 혼합하지 않는다.
