# 편집 후보 선별 v2

이 파이프라인은 기존 수집 결과를 원자료로만 재사용하고, 서울시민 대상 6~7분 방송용 기획 리포트로 확장 가능한 후보만 월·수 오전 9시에 2~3건 선별한다.

## 원칙

- 기존 후보 판정 결과를 그대로 승계하지 않는다.
- 서울시의회·자치구의회·감사·뉴스·SNS·유튜브 자료를 동일한 입력 계약으로 읽는다.
- 건설알림이 등 구현·변경 관측은 단독 후보가 아니라 보강 관측으로 취급한다.
- 제목, 주제, 선정 이유, 시민 질문, 차별화 질문, 근거 링크, 확인 필요 사항을 모두 채울 수 없는 자료는 제외한다.
- 결과는 편집자 검토용이며 자동 브리핑 확정본이 아니다.

## 출력

- `output/briefing_latest.json`: UI와 후속 브리핑이 읽는 정규화 결과
- `output/briefing_latest.md`: 사람이 읽는 결과
- 한 번의 실행에서 최대 3건을 출력한다.
