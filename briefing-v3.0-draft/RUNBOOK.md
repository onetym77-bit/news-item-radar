# 모델 운영 규칙

## 기본값

매일 아침 브리핑은 **Terra medium**으로 실행한다. 후보 탐색, 관심 근거 확인, 경쟁 보도 확인, 데이터·섭외·제작 등급 판정까지 수행한다.

## Sol 승격 조건

다음 중 하나가 있으면 해당 후보만 **Sol medium**으로 재검토한다.

- 핵심 원자료끼리 수치나 산출방식이 충돌함
- 핵심 팩트가 둘 이상 미확인임
- 복잡한 원자료 결합·직접 계산이 필요함
- 법적·평판 위험이 큰 주장임
- 단독 가능성 또는 앵글 판단이 모호함
- Terra가 P0 후보를 확보하지 못함

Sol은 전체 브리핑을 처음부터 다시 만드는 데 쓰지 않는다. Terra가 압축한 상위 3~5건 또는 문제가 된 한 건만 검토한다.

## 정기 점검

주 1회 또는 월 1회 Sol medium으로 최근 브리핑의 탈락·채택 기준을 표본 점검한다. 매일 A/B 비교나 전체 재검색은 하지 않는다.

## 자동화 제약

예약 작업 하나에는 보통 하나의 모델을 고정한다. 따라서 일일 Terra 브리핑과 Sol 정기 점검은 별도 작업으로 운영하는 것이 안정적이다. 현재 대화의 본체 모델 변경은 사용자가 선택해야 하며, 하위 검토 작업만 다른 모델로 라우팅할 수 있다.
