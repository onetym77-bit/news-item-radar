# v1.4 유효 질문 출력 예시

- 탐색 수행 판정: PASS
- 편집 산출 판정: 후보 없음
- 질문 게이트: PASS
- 질문 품질 점수: 11/12
- 출처 프레임: 자치구별 보장액 차이
- 편집적 추가: 동일 사고 조건의 실제 자비 부담 차이와 보험 설계 책임
- 선행보도 질문 확인: 없음
- 독창성 게이트: PASS
- 왜 지금 유형: 새 자료
- 질문 가족 / 부모 item_id: 자치구 안전보험 실수령 격차 / 없음
- 중심 질문: 같은 사고를 당한 서울 시민이 거주 자치구 때문에 치료비를 더 부담하는가.
- 시민 손실 가설: 사고 피해자의 자비 치료비와 청구 포기.
- 경쟁 가설: A 자치구 보험 설계가 격차를 만든다 / B 조건을 표준화하면 격차가 사라진다.
- 판정선: 기사 전환은 실수령액 격차 확인, 축소는 보험 설계 비교, 폐기는 표준화 뒤 격차 소멸.
- 시민 손실 근거 탐색: 보험 민원과 청구 포기 사례 확인.
- 반대 근거 탐색: 동일 보장 조건과 사고 구성 보정 확인.
- 최소 판정 실험: 동일 사고 3종의 자치구별 실수령액 표준화 비교 / 4시간 이내.
