# 유튜브 시민 현상 발견 v2.2

> 비활성 참고 문서다. 2026-09-09부터 `YOUTUBE_DISCOVERY_V2_3.md`의 검색 레인·표현 건강도 규칙을 함께 사용한다.

활성화: 2026-09-08

## 핵심 변경

- 단일 당사자·상담·현장 단서를 `LEAD`, 독립 비언론 채널 두 곳 이상의 반복을 `CORROBORATED`로 분리한다.
- 분류가 불명확하지만 손실 표현이 있는 영상은 버리지 않고 `발굴 검토함`에 둔다.
- 의제별 검색 표현을 평탄화해 모든 군집·표현이 순환하도록 고쳤다.
- 각 의제에서 회차당 두 표현을 검색하고 최신순·관련도순을 함께 사용한다.
- 검색 기간과 누적 관찰 기간을 모두 30일로 맞췄다.
- API 관련도 결과가 실제 군집 주제어를 포함하는지 앵커로 재검사하고 드라마·야담·재연은 별도 격리한다.
- 25개 자치구와 주요 생활권 장소어를 제목·설명에서 확인한다.
- 검색식부터 CORROBORATED까지 단계별 건수를 출력한다.

## 판정

- `LEAD`: 당사자 가능성·상담지원·현장운영자 영상 한 건 이상에 손실 표현이 있거나, 한 군집의 댓글에 손실 표현이 두 건 이상 반복됨.
- `CORROBORATED`: 최근 30일 동안 서로 다른 유효 비언론 채널 두 곳 이상에서 같은 손실 표현이 반복되고, 그중 당사자 가능성 또는 현장·운영자 단서가 한 곳 이상 포함됨.
- `HOLD`: 생활정보·언론 재유통뿐이거나 유효한 시민 단서가 부족함.
- `발굴 검토함`: 손실 표현은 있으나 사연·재연·당사자 여부를 자동 판정할 수 없음.

구체 수치·시간·건수 표기가 있다는 이유만으로 설명 채널을 당사자로 승격하지 않는다. 제목·채널에서 직접 경험 단서가 보이거나 명시적인 현장 역할이 확인돼야 자동 승격한다.

어느 단계도 사실 확인이나 기사 게이트를 대신하지 않는다. 영상과 댓글은 검색어·현장·섭외 단서로만 쓰고 독립 자료와 서울 현장에서 검증한다.

## 실행

- 예약 실행: `py -X utf8 ./interest-radar-v2/collect_source_material_v2_1.py`
- 전체 의제 감사: `py -X utf8 ./interest-radar-v2/collect_source_material_v2_1.py --audit-all`

실행 파일명과 누적 장부명은 기존 예약 작업과의 호환성을 위해 유지한다. 결과 JSON에는 `collector_version: 2.2`와 `_v2.2` 접미사를 쓴다.
