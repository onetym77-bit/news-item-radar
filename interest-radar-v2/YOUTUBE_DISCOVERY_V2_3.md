# 유튜브 시민 현상 검색 v2.3

활성화: 2026-09-09

## 검색 표현의 네 레인

- `BEHAVIOR`: 포기·축소·이동·대기·노동시간 증가 같은 행동 변화
- `EVIDENCE`: 고지서·영수증·통장·문자·정산·앱 화면 같은 비용과 문서
- `SCENE`: 실제 이용·퇴사·이사·대기·폐업을 겪은 후기
- `SOURCE`: 보호자·노동자·임차인·상인 등의 브이로그·일상·인터뷰

문제 이름이나 행정 용어만 검색하지 않는다. 18개 현상 군집마다 네 레인을 두고, 하루 세 회차가 모든 표현을 순환한다.

## 감지력 보존형 검색 예산

YouTube `search.list`의 태평양 시간 기준 일일 기본 한도 100회 가운데 시스템이 직접 쓰는 범위는 60회로 제한하고 40회는 예비분으로 남긴다.

- 정규 수집: 하루 최대 40회
- 수동 점검과 주간 감사: 합계 하루 최대 20회
- 예약 회차: 08:00 14회, 12:00 13회, 17:30 13회
- 상시 감시: 핵심 의제 10개 현상 군집에서 하루 한 표현씩
- 순환 검색: 나머지 30개를 건강도 장부상 가장 오래 실행하지 않은 표현부터 선택

상시 검색도 같은 문장을 매일 반복하지 않는다. 핵심 현상 군집은 유지하되 BEHAVIOR·EVIDENCE·SCENE·SOURCE 가운데 가장 오래 실행하지 않은 레인을 선택한다. 같은 할당량 주기에 성공한 검색식은 다시 호출하지 않는다. 수동 실험은 `--manual`을 써서 예약 회차의 검색식을 중복 소비하지 않는다.

## 검색 표현 건강도

각 표현은 실행할 때마다 다음을 누적한다.

- API 검색 결과
- 군집 앵커 일치·불일치
- 당사자·상담·현장 유형
- 손실 장면
- 서울 장소
- 생활정보·언론·사연 소음

최소 3회 관찰 뒤 다음과 같이 판정한다.

- `ACTIVE`: 계속 탐색
- `REVIEW`: 수집 10건 이상인데 손실 장면 0건, 불일치율 50% 초과, 또는 소음 비중 50% 초과
- `PAUSED`: 3회 이상 실행했지만 수집 통과가 0건

PAUSED 표현은 예약 회차에서 건너뛰고 같은 군집의 다른 표현을 사용한다. 건강도는 `output/youtube_query_health_v2_3.json`에 누적한다.

HTTP 429는 일일 할당량 소진으로 간주하지 않으며 재시도 없이 응답 본문의 `reason`·메시지·`Retry-After`를 저장하고 냉각한다. 실제 `403/quotaExceeded`가 확인된 경우에만 태평양 시간 할당량 주기가 바뀔 때까지 차단한다. 모든 YouTube 호출은 `output/youtube_api_usage_v2_3.json`에 기록한다. API 오류가 나면 마지막 누적 장부의 군집을 `ERROR_CACHED` 상태로 보여주며 0건 수집으로 오인하지 않는다.

## 신호 단계

v2.2의 `LEAD → CORROBORATED` 판정과 발굴 검토함을 유지하되, SOURCE·SCENE 레인에서 제목·채널상 직접 생활 장면이 확인되면 명시적인 피해 표현이 없어도 LEAD가 될 수 있다. 이는 질문을 만들 관찰 단서일 뿐 시민 손실이 확인됐다는 뜻이 아니다. 검색식 건강도는 표현의 생산성을 평가할 뿐 영상의 사실성이나 기사 가치를 판정하지 않는다.

## 실행

- 예약 실행: `py -X utf8 ./interest-radar-v2/collect_source_material_v2_1.py`
- 수동 실험: `py -X utf8 ./interest-radar-v2/collect_source_material_v2_1.py --manual`
- 전체 의제 감사: `py -X utf8 ./interest-radar-v2/collect_source_material_v2_1.py --audit-all`
- 검색식·예산 미리보기: 위 명령에 `--preview-queries` 추가

실행 파일명과 누적 영상 장부명은 기존 예약 호환성을 위해 유지한다. 결과 JSON은 `_v2.3` 접미사를 쓴다.
