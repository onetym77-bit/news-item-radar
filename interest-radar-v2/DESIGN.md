# 서울 기획기사 관심 레이더 v2

운영 규칙은 `agent-system-v1/SYSTEM_MANIFEST.md`와 `SOURCE_FAMILY_REGISTRY.md`를 함께 적용한다.

## 목적

새로 생기는 시민 관심 신호를 넓게 보되, 구조적 시민 문제로 번역되지 않는 행사·소비·예약 화제는 기사 원석으로 세지 않는다.

`현상 포착 → 시민 이해관계 연결 → 질문 품질 → 출처 프레임 차감·최소 판정 → 양방향 근거 탐색 → 기사 게이트 → 서울 현장 검증`

## v1과의 차이

| v1 | v2 |
|---|---|
| 미리 정한 가설에 유튜브 검색어를 끼움 | 관심 렌즈별 원천 신호를 수집 |
| 서울 키워드를 초기에 강제 | 전국 신호를 먼저 보고 서울성과 검증 가능성을 나중에 판단 |
| 유망/비유망을 자동 판정 | 자동화는 신호 소재까지만, 기사 판정은 편집 단계 |
| 개별 영상 수치 중심 | 같은 현상에 대한 독립 채널·검색 변화·공간/소비 데이터의 교차를 요구 |

## 유튜브 발견 v2.3

유튜브의 역할은 완성된 기사나 인기 주제를 찾는 것이 아니라 행정 발표 전에 나타나는 시민의 비용·시간·포기·위험 언어를 포착하는 것이다.

- 인기목록은 수집하지 않는다. 예약 회차마다 9개 생활 의제 중 4개를 순환한다.
- 문제 이름 대신 `BEHAVIOR 행동 변화`, `EVIDENCE 비용·문서`, `SCENE 생활 장면`, `SOURCE 당사자 형식` 네 레인의 시민 표현을 순환한다. 회차별로 각 의제에서 두 표현을 `최신순`과 `관련도순`으로 나눠 찾는다.
- 개별 영상을 순위화하지 않고 동일 질문 묶음의 영상을 최근 30일 동안 누적한다.
- 당사자 가능성·상담지원·현장운영자 한 곳에서 손실 표현이 발견되거나 SOURCE·SCENE 레인에서 직접 생활 장면이 확인되면 `LEAD`다. 서로 다른 비언론 채널 두 곳 이상에서 손실이 반복되고 당사자·현장 단서가 포함되면 `CORROBORATED`다. 장면형 LEAD는 시민 손실의 증거가 아니며 숫자 표기만으로 설명 채널을 당사자로 승격하지 않는다.
- `LEAD`는 후속 검색·원문 확인 대상이지 사실 근거나 기사 후보가 아니다. `CORROBORATED`도 독립 자료로 검증하기 전에는 기사 후보가 아니다.
- 생활정보·방법·레시피·혜택 설명과 언론 재유통은 시민 신호 수에서 제외한다. 손실 표현은 있으나 유형이 불명확한 영상은 버리지 않고 `발굴 검토함`에 둔다.
- 댓글은 사실 근거가 아니라 반복 표현과 후속 검색어·섭외 대상을 찾는 단서로만 사용한다.
- 전문가 관찰 채널은 구조적 배경 가설용으로 분리하고 시민 현상 군집 점수에 넣지 않는다.
- 매 실행은 `검색식→API 결과→고유 영상→상세 조회→강제 제외→수집 통과→새 고유 영상→LEAD→CORROBORATED` 수를 기록한다.
- 표현별 API 결과·주제 일치·현장성·손실 장면·서울 연결을 누적한다. 3회 이상 관찰한 뒤 수집 0건은 `PAUSED`, 손실 장면 0건·불일치 또는 소음 50% 초과는 `REVIEW`로 표시한다.

## 입력 레이어

1. **구조 탐색** — 핵심 생활 의제의 제도·시장·공간 변화
2. **시민 발현** — 비용·위험·시간·권리 손실이 드러난 행동과 진술
3. **검증** — 규모·지속성·분배·책임 주체와 반증 조건

## 발견 범위

매 회차는 주거·노동·돌봄·의료·교육·교통·생활물가·디지털 권리·안전·환경·지역경제 가운데 핵심 5개 이상을 탐색한다. 출처군별 건수를 강제하지 않는다. 유튜브와 네이버 흐름은 시민 언어와 현장 단서일 뿐 의제 선택을 지배하지 않는다. 감사·판결·예산·공시·행정통계·민원은 구조 변화를 보여줄 때 발견 원천으로 쓸 수 있다.

## 제외 규칙

- 발표 내용과 기관의 자기평가를 그대로 결론으로 삼은 소재
- 방송 뉴스 재유통, 사건 단발 영상, 광고·창업 홍보
- 게임·해외 여행·연예·개인 일상처럼 서울 시민 경험으로 일반화하기 어려운 소재
- 한 채널·한 영상만으로 사실·규모·대표성을 단정한 소재
- 공연·축제·팝업·관광·티켓·예약 중 일정·가격·이용 팁 이외의 분해·비교 질문을 만들 수 없는 소재
- 단순 가격 비교, 인기 순위, 이용 팁, 행사 종료 뒤 남지 않는 혼잡

## 통과 규칙

신호는 먼저 객관적 현상, 시민 이해관계, 검증 경로를 확인한다. 이후 `agent-system-v1/QUESTION_QUALITY_GATE.md`에 따라 긴장·반전, 시민 손실, 분포·배제, 경쟁 가설, 책임·변경 가능성, 반증·판정선을 평가한다. PASS 원석에는 중심 질문 한 개와 경쟁 가설 두 개 이상을 만들고 실제 확인 전에는 기사 후보로 부르지 않는다.

품질 PASS 원석은 `agent-system-v1/ORIGINALITY_AND_TEST_GATE.md`에 따라 출처 프레임과 편집적 추가를 분리한다. 독창성 PASS와 24시간 이내 최소 판정 실험이 있는 원석만 우선 검증하며 시민 손실 근거와 반대 근거를 모두 찾는다. 공공·공공연구 출발 원석이 60%를 넘으면 비공공 경로 보정 탐색을 한 차례 수행한다.

- `LEAD` 뒤 독립 채널 두 곳 이상에서 같은 생활 현상 확인
- 검색 관심의 유의미한 상승 또는 지속
- 구조 레이더의 관련 변화
- 현장에서 확인 가능한 장소·이용자·사업자 접점

## 결과물

하루 질문 원석은 5~10건을 목표로 하되 0~4건도 정상이다. 이 중 2~4건을 우선 검증하고 기사 게이트를 통과한 최종 브리핑은 최대 3건이다.

각 건에는 다음을 반드시 적는다.

- 시민이 공감할 장면
- 장면 상태: 관찰됨/당사자 진술/간접 보도/취재 예정/없음
- 지금 포착된 신호와 아직 모르는 사실
- 최초 원천, 출처군, 근거 계보
- 서울에서 검증할 공공데이터
- 1차 현장 위치 또는 섭외 대상
- 섭외 실패 시 대안
