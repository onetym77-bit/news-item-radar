# 유튜브 시민 신호 의미 검증 그림자

목적은 검색어가 같은 영상을 기사 아이템으로 착각하지 않는 것이다. 수집기의 `CORROBORATED`는 검색 군집의 반복일 뿐, 같은 시민 현상이나 서울 현상을 확인한 결과가 아니다.

## 진입 조건

- 수집기 기준 `CORROBORATED`
- 검토 가능한 비언론 채널 2곳 이상
- 군집이 주장하는 구체적인 결과 행동이 있는 영상 2개 이상
- 당사자 가능성 또는 현장·운영자 영상 1개 이상
- 위 결과 행동 영상 안에 서울 사건 지역 단서 1개 이상

언론 재유통, 생활정보·설명, AI 창작·재연, 분류 대기 영상은 위 조건의 근거로 세지 않는다. 상담·지원 영상은 맥락으로 쓸 수 있지만 그것만으로 시민 직접 신호를 만들지 않는다. 법률사무소·상담기관의 연락처나 사무실 주소에 나온 서울 지명은 사건 지역으로 세지 않는다.

## 의미 검증

한 번의 구조화 모델 호출로 최대 3개 군집을 함께 읽는다. 다음을 분리해 본다.

1. 제목·설명에 실제 경험, 행동 변화 또는 현장 운영 장면이 있는가
2. 서로 다른 영상이 검색어만 같은 것이 아니라 같은 현상을 말하는가
3. 서울 언급이 우연한 지명이 아니라 현상 자체와 연결되는가
4. 다른 설명은 무엇이며 무엇을 먼저 확인해야 가설을 가를 수 있는가
5. 6~7분 방송에서 확인 가능한 사람·장소·문서 장면이 있는가

`REVIEW`도 사실 확인이나 기사 후보 승격이 아니다. 원문에 연속해서 존재하는 인용과 검증 질문을 갖춘 검토 단서일 뿐이다. `HOLD`는 추가 문맥이 필요하고, `NO_SIGNAL`은 검색어 일치 외에 같은 시민 현상을 뒷받침하지 못한다.

## 운영 경계

- 결과는 `youtube-semantic-shadow-<run id>` artifact로 7일만 보관한다.
- `editorial-v4/output/latest.json`, 공개 화면, `ITEM_LEDGER.csv`에는 자동 반영하지 않는다.
- PR은 모델을 호출하지 않고 실제 누적 장부에 사전선별만 실행한다.
- main 수동 실행 또는 월·수 편집 실행에서 사전선별 대상이 있을 때만 모델을 1회 호출한다.
- 그림자 결과를 실제 사람이 확인한 뒤에만 통합 편집기 입력 승격을 별도 변경으로 검토한다.

## 실행

```bash
python -X utf8 interest-radar-v2/review_youtube_context.py --dry-run
python -X utf8 interest-radar-v2/review_youtube_context.py --model gpt-5.6-luna
```

API 키는 `OPENAI_API_KEY` 환경변수로만 전달한다.
