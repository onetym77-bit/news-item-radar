# 시민제안 문장 형식 분류 시험

이 시험은 [상상대로 서울 공식 시민제안 목록](https://idea.seoul.go.kr/front/allSuggest/list.do?tab=cateAll)의 첫 고유 제안 최대 5건과 각 상세를 직접 읽는다. 구의회 비회기 보완 소스의 세 번째 경로를 검토하기 위한 읽기 전용 시험이며, 핵심 발굴 소스나 일일 브리핑에 편입하지 않는다.

## 결과의 의미

- **당사자 경험 진술형:** 제안자가 자신의 신청·방문·이용 등과 불편을 함께 서술한 형식. 실제 발생 여부는 미확인이다.
- **전언·소문형:** 들은 이야기나 소문을 전달한 형식. 공식 발표나 제도 시행의 증거가 아니다.
- **정책 아이디어형:** 설치·도입·개선 등 제안을 중심으로 한 형식. 현행 제도 부재 또는 시민 피해의 증거가 아니다.
- **판별 대기:** 상세 제목 대응이 확인되지 않거나 위 형식에 들어가지 않은 경우.

경험 진술형·전언형에는 분류에 쓰인 짧은 근거 문장을 최대 240자까지 붙인다. 연락처·주민번호 형식·정확한 도로명 번지·동호수·명시된 이름은 가린다. 이 문장은 분류를 설명하는 사람 검토용 앵커이지 사건 발생의 증거가 아니다. 정책 아이디어형은 원문 인용을 저장하지 않는다. 모든 항목에는 첫 확인 경로만 붙인다. 제목·본문 문구에 흔한 표현을 찾는 규칙이므로 복합 진술, 부정문, 인용문, 관련글 혼입을 완벽히 판별하지 못한다. 결과의 분류는 사람이 공식 원문과 대조해야 한다. 공감·비공감·조회 수는 수집하거나 판단에 사용하지 않는다.

## 실행과 보관

GitHub Actions의 **Probe citizen proposal statements**를 수동 실행하거나 관련 파일 PR에서 시험한다. 첫 5건, 공식 HTTPS 호스트만, 응답당 최대 2 MB·20초 제한이다. 실행 결과는 7일짜리 Actions 산출물 두 파일로만 보관하며 main에 자동 커밋하지 않는다.

산출물은 고유 번호·제목·게시일 후보·목록 상태 후보·공식 링크·문장 형식·첫 확인 경로·원본 지문을 담는다. 경험·전언형에는 가려진 짧은 분류 근거와 제목에서 찾은 장소 후보·본문의 시간 표현 후보도 담지만 모두 미확인 맥락으로 표시한다. 작성자명, 연락처, 원문 전체, HTML은 저장하지 않는다. 짧은 문장 가림은 완전한 비식별화를 보장하지 않으므로 7일 산출물 밖으로 자동 전파하지 않는다. 제목에 드문 민감정보가 들어갈 가능성은 기본 연락처 가림만으로 완전히 제거할 수 없으므로, 확대 전에 사람 검토 또는 더 엄격한 제목 정책이 필요하다.

HTTP 성공, 상세 제목 대응, 문장 형식 분류, 사실 검증, 기사 판단은 각각 별도 상태다. 첫 관측이나 숫자 증가를 신규 피해·신규 기사로 표현하지 않는다. 공식 목록의 게시일은 화면 근접 텍스트의 후보이며, 상세 기록의 작성일과 대조되기 전까지 완전 검증 날짜가 아니다.

## 다음 판정 기준

실제 실행 결과에서 상세 제목 대응률, 분류의 사람 확인 정확도, 확인 가능한 시민 경험 진술의 비중을 점검한다. 표본이 5건이므로 이 단계만으로 소스 수율이나 정밀도를 주장하지 않는다. 질문 품질·독창성·최소 검증 및 기사 게이트는 기존 시스템과 분리해 유지한다. 기존 질문 장부와 일일 예약은 변경하지 않는다.
