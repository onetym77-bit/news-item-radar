# 의회 비회기 발굴 공백 보완안
확인일: 2026-09-14

## 판단

25개 구의회 연결은 지역 범위를 넓히지만, 회기마다 자료가 몰리는 공급 구조를 바꾸지는 않는다. 시의회와 구의회를 26개의 독립적인 시민 경험 출처로 계산해서도 안 된다.

운영은 두 흐름이 필요하다.
1. 새 자료 관측: 새 회의록·사업 기록·민원 통계·시민제안을 확인한다.
2. 축적 질문 검증: 회의가 없는 날에도 기존 질문의 지역·대상·기간 비교, 반대 설명, 후속 자료를 확인한다.

새 게시물 유무와 새 질문의 가능성은 다르다. 과거 자료도 현재까지 이어지는 현상을 검증하는 출발점이 될 수 있지만, 오래된 사실을 오늘 발생한 일처럼 제시하지 않는다.

## 비회기 보완 시험 우선순위

### 1. 응답소 민원통계 — 기존 공개사례 수집과 분리

[공식 통계 화면](https://eungdapso.seoul.go.kr/gud/chart/chart_progress.do)

9월 14일 웹 확인에서 화면 기준일은 9월 11일이며, 9월 10일까지의 일별 추이와 자치구별·신청방법별·분야별·처리기관별 집계를 읽었다. 화면은 전일 기준이라고 안내한다. 다만 웹 읽기의 캐시 시점과 실제 사이트 갱신 시점은 구분해야 하며, 매일 자동 수집 성공을 검증한 것은 아니다.

공개 민원사례 게시판이 뜸하다고 응답소 전체가 느린 소스인 것은 아니다. 통계는 별도 경로로 시험할 가치가 있다.

- 질문 예시: 민원이 많은 구는 실제 불편이 큰가, 생활인구·신고 경로·반복 신고를 고려하면 순위가 달라지는가?
- 필요한 추가 자료: 집계 정의, 기간이 일치하는 인구·이용량, 가능하다면 중복 및 구별 세부 분야.
- 금지할 해석: 민원 건수를 피해자 수로 표현하거나 별개인 구별·분야별 분포를 구×분야 교차표처럼 결합하지 않는다.
- 첫 시험: 기준일·대상기간·지표 정의를 저장하고 같은 기간끼리 비교되는지 확인. 기준일이 안 바뀌면 신규 통계로 중복 계상하지 않는다.

### 2. 건설알림이 계약·집행·공정 — 발표 뒤 실제 진행 관측

[계약목록](https://cis.seoul.go.kr/TotalAlimi_new/CnrtList.action) / [집행목록](https://cis.seoul.go.kr/TotalAlimi_new/CnrtExList.action)

직접 읽은 계약목록에 9월 12일과 14일 등록 자료가 존재한다. 회기와 무관한 업무 기록으로 볼 수 있으나 고정 갱신주기는 확인하지 못했다. 상세 이동 방식과 계약번호 연결은 추가 수집시험이 필요하다.

- 질문 예시: 공사기간 연장과 비용 증가가 같은 시설에서 반복된다면 물가·설계 변경으로 설명되는가, 최초 계획에 빠진 조건이 있었나?
- 필요한 추가 자료: 원계약과 변경계약, 변경 사유, 예정·실제 공정, 주민 이용 중단 기간.
- 금지할 해석: 장기계속계약의 차수를 중복 합산하거나 계약금액·전체 사업비·지급액을 혼동하지 않는다. 증액 자체가 낭비의 증거는 아니다.
- 첫 시험: 특정 계약의 원본과 변경 내역을 연결하고, 시민 서비스 변화로 이어지는 질문이 생기는지 확인한다.

### 3. 상상대로 서울 시민제안 — 행정기록에 드러나지 않는 생활 경험

[공식 시민제안 목록](https://idea.seoul.go.kr/front/allSuggest/list.do?tab=cateAll)

직접 읽은 목록에서 9월 6~7일 여러 생활 관련 제안을 확인했다. 검색색인의 최신 게시일과 직접 읽은 목록의 최신일은 다를 수 있다. 제안의 내용이 사실이라는 의미도 아니다.

- 질문 예시: 온라인으로 자격 확인이 끝나도 방문 발급이 필요한 공공서비스가 남아 있다면 누구에게 시간·이동 부담이 집중되는가?
- 필요한 추가 자료: 현재 신청·발급 절차와 예외, 당사자 경험, 현장·공식 안내 대조.
- 금지할 해석: 공감수는 대표성·사실성 지표가 아니다. 단순 아이디어·소문·직접 경험을 구분한다.
- 첫 시험: 적은 수의 원문에서 경험 진술을 추출해 현재 규정과 대조한다. 마스킹된 이름을 복원하거나 연락처·구체적 개인 신상을 따로 저장하지 않는다.

### 4. 환경영향평가 공고·진행현황 — 사업 간 누적 부담

[공식 공고·진행현황](https://eims.seoul.go.kr/eims/usr/main/index.do?tr_code=rsite)

목록 확인에서는 9월 초·중순의 공고와 상태 수정이 보였다. 사업 절차에 따른 수시 공급으로 판단하되 고정 주기는 미확인이다. 첨부 원문과 상세 연결은 별도 시험이 필요하다.

질문 예시: 인접한 재개발 사업의 교통·소음 영향은 따로 평가되는데, 동시에 진행될 때의 부담은 어디에서 검토하는가? 사업자 예측과 행정기관 의견을 분리하며 검토완료를 승인·착공과 같은 상태로 해석하지 않는다.

### 5. 정보소통광장 결재문서 — 접근 가능성 검증 후 편입

[결재문서 진입](https://opengov.seoul.go.kr/sanction)

공개 문서의 제목·기관·생산일·공개구분은 유용하지만 이번 웹 점검에서는 목록과 상세 시간초과가 있었다. 현재 공급량과 자동 본문 확보 가능성은 미확인이다. 접속 실패를 자료 부재라고 기록하지 않는다.

질문 예시: 공공시설 교체 순서는 위험도·이용량에 따르는가, 기관별 예산 사정에 따라 달라지는가? 제목 공개와 근거·첨부 공개를 구분하고, 사업연도와 실제 생산일을 별도로 저장한다.

## 상시 보완원과 역할 구분

- [상권분석 출처·주기](https://golmok.seoul.go.kr/source.do): 확인한 자료표에는 분기 자료와 더 오래된 기준자료가 섞여 있다. 일일 신착 소스가 아니라 같은 기준기간의 업종·지역 비교 질문을 재검토하는 자료다. 추정매출을 전수 실매출로 부르지 않는다.
- 감사 결과·예산 결산·연구보고서: 공급 간격은 길 수 있어도 구조 설명과 반대 근거에 유용하다. 매일 새 자료를 내놓는 소스로 기대하지 않는다.
- YouTube: 기존 관심 레이더에서 서울 현장·당사자 단서를 보강한다. 언론 재유통을 독립 시민 증언으로 세지 않는다. 전수검색 확대보다 기존 관측 채널의 신규 게시물과 질문별 소량 확인을 우선하는 시험안을 유지한다. 이번 변경은 YouTube 요청량이나 예약을 바꾸지 않는다.

## 연결 이후 평가 기준

소스별로 다음을 따로 기록한다.

| 항목 | 의미 |
|---|---|
| 접근·본문 | 목록만 읽힌 것인지 원문까지 읽힌 것인지 |
| 관측 변화 | 첫 관측 / 확인범위 내 새 문서 있음 / 없음 / 실패로 판단 불가 |
| 자료 공급 간격 | 직접 누적 관측한 간격. '매일 확인'과 '매일 생산'은 다름 |
| 편집 추가 질문 | 원문 주장 반복을 넘어 새 비교·설명·책임 질문이 있는지 |
| 최소 검증 | 처음 확인할 자료와 경쟁 설명을 제시할 수 있는지 |
| 유지·기각 | 근거가 보강됐는지, 가설을 접었는지. 기각도 검증 성과로 기록 |

이번에는 연결 대상과 보완소스 우선순위를 정리했다. 위 신규 비의회 소스의 수집기 설치·일일 예약 변경·핵심소스 승격은 아직 수행하지 않았다. 당장의 첫 보완시험 대상은 응답소 통계, 건설알림이, 시민제안의 세 경로다.
