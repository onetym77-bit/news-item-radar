# 구의회 발언 문맥 L3 그림자 검토

## 범위

2026-09-22 L2에서 비임시본·본문·회의일 대응을 확인한 7개 회의록 URL을 고정했다. 최신 회의 1건씩은 의회 전체를 대표하지 않는다. 종로 등 임시본과 접속 실패를 0건으로 해석하지 않는다.

## 무엇을 하는가

PR에서는 API 키 없이 고정 7건의 원문 접근·본문 파싱·지문 변화만 확인한다. 병합 후 수동 실행에서만 OPENAI_API_KEY로 고정 회의록 7건을 각각 모델로 읽고, 검증 단서가 나온 경우 이를 별도 편집 데스크 모델이 한 번에 재심사한다(최대 8회 모델 호출). 키워드 또는 안건명만 보고 문제를 추론하지 않는다. 회의록당 최대 1개의 검증 질문, 0건도 정상이다.

1차 REVIEW는 검증할 단서이지 방송 아이템 승인이 아니다. 2차 편집 판정은 취재 우선 검토(PURSUE), 선확인(VERIFY_FIRST), 기획 우선순위 낮음(LOW_PRIORITY)으로 분리한다. 시민에게 닿는 구체적 경로와 6~7분 방송의 장면·당사자·대조 자료를 본다. 현재 통계가 없다는 이유만으로 배제하거나 행정 지출을 자동으로 시민 피해로 읽지 않는다. HOLD라도 구체적인 서비스·예산 단서가 있으면 원문 앵커와 다음 확인 조건을 남긴다.

각 질문에는 원문에 연속 등장하는 짧은 발언 앵커, 발언에서 읽히는 사안, 확인할 시민 이해관계, 가설과 반대 설명, 이를 가를 첫 취재, 6~7분 방송의 장면·자료 경로가 있어야 한다. 의원의 말은 사실 확인 전 주장이다. 발언 인용이 맞아도 나머지 해석·취재 가설은 사람 검토 대상이다.

## 승급하지 않는 것

결과는 7일 읽기 전용 아티팩트에만 두고 원문 전체를 저장하지 않는다. 현재 구의회 성숙도는 L1로 유지한다. L3 검증 질문은 editorial-v4의 정식 입력, 공개 브리핑, 장부, 기사 승인에 자동 연결하지 않는다. 편집자가 실제 가치와 오판을 확인한 뒤 L4 그림자 평가와 소스 승급을 별도로 결정한다.

## 실행 경로

- PR의 Review fixed district-minute context L3 shadow: 무과금 본문·계약 시험.
- 병합 뒤 Actions의 같은 워크플로우 수동 실행: 최대 8회 유료 모델 호출(회의록 7회 + 독립 편집 판정 최대 1회). 결과 요약은 Actions 실행 화면과 district-l3-context 아티팩트에서 확인.
- API 키가 없으면 수동 의미 검토는 실패하고, 빈 결과를 아이템 부재로 발표하지 않는다.

## 확인할 실패 유형

- 고정 URL의 접속/본문 실패, 회의일 충돌, 원문 지문 변경은 각각 별도 표시한다.
- 절차·표결·조례명만 있는 회의에서 REVIEW가 나오면 오탐으로 판정한다.
- 발언 앵커가 본문과 일치하지 않거나 보편적 질문·반대 설명 없는 질문이면 자동 보류한다.
- 1차 REVIEW를 곧바로 기획 가치로 해석하지 않는다. 양천구의 소액 내부 교육비처럼 질문은 가능해도 시민에게 닿는 경로와 방송 구성이 약할 수 있다.
- 중랑구 셔틀버스처럼 HOLD에 결정·예산 단서가 있으면 단서를 지우지 않고 실제 노선·운행·이용자 변화의 확인 방법을 남긴다.
- 2차 편집 판정 실패 시 실행이 실패로 표시되고 검증 단서는 방송 가치 미평가로 유지한다.
- 7건의 결과로 구의회 전체 정밀도나 주 2회 아이템 수율을 추정하지 않는다.
