# 구의회 발언 문맥 L3 그림자 검토

## 범위

2026-09-22 L2에서 비임시본·본문·회의일 대응을 확인한 7개 회의록 URL을 고정했다. 최신 회의 1건씩은 의회 전체를 대표하지 않는다. 종로 등 임시본과 접속 실패를 0건으로 해석하지 않는다.

## 무엇을 하는가

PR에서는 API 키 없이 고정 7건의 원문 접근·본문 파싱·지문 변화만 확인한다. 병합 후 수동 실행에서만 OPENAI_API_KEY로 최대 7회 모델을 호출해 회의록 전체 발언 문맥을 읽는다. 키워드 또는 안건명만 보고 문제를 추론하지 않는다. 회의록당 최대 1개의 검증 질문, 0건도 정상이다.

각 질문에는 원문에 연속 등장하는 짧은 발언 앵커, 발언에서 읽히는 사안, 확인할 시민 이해관계, 가설과 반대 설명, 이를 가를 첫 취재, 6~7분 방송의 장면·자료 경로가 있어야 한다. 의원의 말은 사실 확인 전 주장이다. 발언 인용이 맞아도 나머지 해석·취재 가설은 사람 검토 대상이다.

## 승급하지 않는 것

결과는 7일 읽기 전용 아티팩트에만 두고 원문 전체를 저장하지 않는다. 현재 구의회 성숙도는 L1로 유지한다. L3 검증 질문은 editorial-v4의 정식 입력, 공개 브리핑, 장부, 기사 승인에 자동 연결하지 않는다. 편집자가 실제 가치와 오판을 확인한 뒤 L4 그림자 평가와 소스 승급을 별도로 결정한다.

## 실행 경로

- PR의 Review fixed district-minute context L3 shadow: 무과금 본문·계약 시험.
- 병합 뒤 Actions의 같은 워크플로우 수동 실행: 최대 7회 유료 모델 호출. 결과는 실행의 district-l3-context 아티팩트에서 확인.
- API 키가 없으면 수동 의미 검토는 실패하고, 빈 결과를 아이템 부재로 발표하지 않는다.

## 확인할 실패 유형

- 고정 URL의 접속/본문 실패, 회의일 충돌, 원문 지문 변경은 각각 별도 표시한다.
- 절차·표결·조례명만 있는 회의에서 REVIEW가 나오면 오탐으로 판정한다.
- 발언 앵커가 본문과 일치하지 않거나 보편적 질문·반대 설명 없는 질문이면 자동 보류한다.
- 7건의 결과로 구의회 전체 정밀도나 주 2회 아이템 수율을 추정하지 않는다.
