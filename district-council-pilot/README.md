# 자치구의회 5곳 표본 시험

목적: 서울시의회 외 발굴 후보인 자치구의회의 수집 가능성과 질문 발전 가능성을 시험한다. 2026-09-14 선택한 강남·관악·노원·마포·성동은 지역·사이트 구조를 달리한 목적표본이며 서울 25개 구의 대표표본이 아니다.

## 고정 표본과 보완 탐색

- 각 공식 최근목록 첫 페이지 순서대로 서로 다른 회의록 4건, 최대 20건. 선택 시점과 목록 순위를 남긴다.
- 접근 실패·빈 본문·해석 불가 연결은 다른 문서로 대체하지 않는다. 목록에 없으면 표본 부족으로 기록한다.
- 회의일과 수집일을 구분한다. 공개일이 없으면 미확인이다. 회의 후 경과일은 공개 지연 일수의 추정값이 아니다.
- 임시본은 표시하고 최종 취재 판단 전 확정본을 다시 확인한다.
- 검색·수동 탐색으로 찾은 좋은 사례는 별도 보완 사례로 기록하며 고정 표본의 성공률에 더하지 않는다.
- 최신 4건이 의장단 선출 등 절차 안건에 몰리면 그 구성이 결과다. 같은 조건의 다음 회기·위원회 표본에서 보완한다.

## 두 단계 평가

1. 수집: 목록 접근 → 4건 선정 → 본문 확인. HTTP 성공만으로 본문 성공을 선언하지 않는다. 실패와 빈 본문은 원인별로 기록한다.
2. 편집: 자동 검토 문단은 미판정이다. 원문 전체에서 현상·당사자·비교·경쟁가설·판정선·첫 확인 자료를 검토한다. 자동 점수/문단 수는 질문 정밀도가 아니다.

자료의 새로운 수치나 위법 근거가 없어도 구체적 생활 현상에서 질문을 만들 수 있다. 의원 질의, 집행부 답변, 별도 독립 확인은 구분한다. 같은 회의록의 두 발언은 독립 출처 둘이 아니다. 답변 없음은 동의나 관리 부실의 증거가 아니다.

같은 회의록에서 여러 사안은 허용하지만 같은 사업·현상·시기의 반복은 한 질문 가족으로 묶는다. 20건 중 질문이 나온 문서 수와 중복 제거 사안 수를 별도로 보고한다. 원문 전체 검토가 끝나지 않으면 편집 정밀도는 미산출이다.

이번 20건은 확대시험 여부를 판단하는 탐색 단계다. 핵심 발굴원 승격에는 회기·위원회를 넓힌 후속 표본과 사람 판정이 추가로 필요하다.
