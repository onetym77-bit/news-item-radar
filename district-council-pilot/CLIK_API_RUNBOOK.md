# 지방의정포털 OpenAPI 운영 기준

## 목적

국회도서관 지방의정포털 회의록 OpenAPI를 서울 25개 자치구의회의 공통 수집 경로로 사용한다. 의회마다 다른 목록·본문 화면을 직접 해석하는 부담을 줄이되, API 장애가 자료 0건이나 신규 회의록으로 오인되지 않게 한다.

## 인증 정보

- GitHub Actions 저장소 시크릿 이름: `CLIK_API_KEY`
- 키는 코드, 설정 파일, 실행 로그, 산출물, 아티팩트에 저장하지 않는다.
- API 오류에는 예외 종류만 남기고 응답 URL이나 키 값은 남기지 않는다.

## 수집 경로

1. 시크릿과 `clik_assembly_id`가 있으면 지방의정포털 API를 우선 사용한다.
2. 목록은 의회별 최근 20건 이하, 본문 L2는 최근 1건만 읽는다.
3. API 호출이 실패하면 기존 공식 의회 홈페이지 수집기로 전환한다.
4. API와 홈페이지 사이에서 경로가 바뀐 첫 실행은 `BASELINE_ROUTE_CHANGED`로만 저장한다. URL 체계 차이를 신규 회의록으로 세지 않는다.
5. 공개 링크에는 인증키가 없는 지방의정포털 문서 화면 URL만 사용한다.

## 호출량 경계

- 공식 문서상 목록은 호출당 최대 100건, 키당 하루 최대 1,000회이다.
- 일일 감시는 25개 의회 목록을 각 1회 조회한다.
- L2 수동 실행은 의회별 목록 1회와 상세 1회 범위이다.
- L3는 L2에서 선택한 최대 5개 문서만 상세 재검증한다.
- 전체 보관소를 순회하거나 페이지를 무제한 넘기지 않는다.

## 편집 경계

이 연결은 수집 안정성을 높이는 작업이다. API 응답은 곧바로 질문, 아이템 장부, 정식 브리핑에 들어가지 않는다. 기존 L2 본문·식별정보 확인과 L3 발언 문맥 그림자 검토를 통과한 뒤에도 독립 편집 판정이 필요하다.

## 장애 해석

- `UNKNOWN_COLLECTION`: 접속 또는 응답 검증 실패이며 회의록 0건이 아니다.
- `UNKNOWN_LIST_WINDOW`: 목록 구조나 식별정보를 확정하지 못한 상태다.
- `BASELINE_ROUTE_CHANGED`: 수집 경로만 바뀌어 새 기준선을 만든 상태다.
- `API_KEY_MISSING`: API로 확인했던 문서를 L3에서 다시 읽을 인증 정보가 없는 상태다.
